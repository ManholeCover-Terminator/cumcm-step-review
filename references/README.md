# 参考库索引

按需读取，禁止一次性全部加载。目录结构：

```text
references/
  README.md                  # 本索引
  阶段流程.md                 # 十部分推进手册（必读：开始/推进任一部分）
  优秀论文写法指南.md          # 国赛优秀论文逐部分写法（必读：每个部分写入草稿前）
  优秀论文语料分析报告.md      # 2021–2025 62 篇获奖论文实证：章节结构频率、逐部分句模、分题型差异
  摘要写作/                    # 摘要专用模块：SKILL.md（93 篇摘要语料方法论）+ analysis/templates/
                              # mistakes/checklist/example + 摘要汇总.md/.docx（93 篇真实摘要语料）
  质检清单.md                 # 各阶段作者自检 + 独立质检 + 最终验收
  模型选型树.md               # 五大题型 → 候选算法池 + 防错速查
  写作与图表规范.md           # 论文结构、三线表、图表规范、防错清单
  国赛规范.md                 # 官方格式规范（2026）、评审权重、优秀论文写法、篇幅与提交清单（当届规则需核验）
  math_modeling_norms.md     # 完整规范知识库（题型防错/选型/写作/图表）
  算法索引.md                 # 算法资源导航（配合 assets/*.md）
  Subagent调度.md            # 可选独立质检门禁的调度协议（默认关闭）
  roles/
    建模手/                   # 工作流程、常见模式、建模设计理论、质检清单、前置合同
    编程手/                   # 可视化规范、图表选择与避坑、数据剖析解读、期刊规范、
                              # 视觉回审、MATLAB规范、常见模式、工作流程、质检清单、面板模板
    论文手/                   # 写作规范、章节模板、自审框架、LaTeX格式规范、论文格式规范、
                              # 工作流程、英文化工作流
  绘图参考/                   # scipilot：图表选择决策、18 条避坑、期刊规格、绘图配方、
                              # 投稿清单、视觉复核、数据剖析解读
```

## 使用时机

| 任务 | 读取 |
| --- | --- |
| 开始或推进任一部分 | `阶段流程.md` |
| 把某部分写入论文草稿 | `优秀论文写法指南.md` 对应章节 + `优秀论文语料分析报告.md` 对应小节 + `写作与图表规范.md` + `roles/论文手/章节模板.md` |
| 写、改或评摘要 | `摘要写作/摘要写作方法论.md` +（按需）`摘要写作/analysis.md`、`摘要写作/templates.md`、`摘要写作/mistakes.md`、`摘要写作/checklist.md`、`摘要写作/example.md`、`摘要写作/摘要汇总.md` |
| 选择模型或查算法 | `模型选型树.md` + 对应 `assets/*.md` |
| 绘图与配色 | `写作与图表规范.md` + `scripts/plot_style.py` + `assets/期刊配色方案.md` + `绘图参考/` |
| 图表自检 | `质检清单.md` + `scripts/figure_audit.py` + `绘图参考/visual_review.md` |
| 写作 | `优秀论文写法指南.md` + `优秀论文语料分析报告.md` + `写作与图表规范.md` + `roles/论文手/` |
| 最终验收 | `质检清单.md` + `scripts/paper_check.py` |
