# 期刊图表规范

本文件吸收自 scipilot-figure-skill 的 journal_specs.md
（MIT License, Copyright (c) 2026 Haojae）。数学建模竞赛的**当届官方模板
始终优先**：官方规定了尺寸、字号、字体或格式时，以官方为准并记录在复现清单中；
本表用于官方未规定、或用户明确要求 Nature/SCI 风格时的基线。

> 编程手默认采用按最终印刷尺寸设定的字号基线（正文标签 8.5–11pt、最小 ≥7.5pt，
> 按图宽线性插值，不取整数 10 作整图缩放），避免图大字小和 AI 默认痕迹；下表各期刊的字号区间属于官方规范信息，
> 当目标期刊有明确字号规定时应以官方为准，并可在调用
> `apply_publication_style()` 后显式覆盖。

## Nature 系列

涵盖 *Nature*、*Nature Methods*、*Nature Communications* 等。

| 维度 | 要求 |
|---|---|
| 单栏宽 | **89 mm ≈ 3.5 inch** |
| 双栏宽 | **183 mm ≈ 7.2 inch** |
| 最大高 | 247 mm ≈ 9.7 inch（不超过一页） |
| 字号 | 标签 / 刻度 5–7 pt，绝不小于 5 pt |
| 推荐字体 | **Helvetica / Arial**（无衬线） |
| 矢量首选 | **EPS** / PDF / AI |
| 位图 | TIFF / PNG，**>= 300 DPI**；彩色图 RGB；线条图 >= 600 DPI |
| 行宽 | 0.25–1 pt（matplotlib 默认 1 pt 偏粗，建议 0.6） |
| 颜色 | RGB；色盲安全；避免红绿对比 |
| 子图标签 | **a, b, c**（小写、加粗、放左上角） |

**坑**：Nature 极其强调“按最终尺寸出图”——投稿系统会按 mm 计算字号是否合规。

## Science

| 维度 | 要求 |
|---|---|
| 单栏宽 | **55 mm ≈ 2.2 inch**（极窄） |
| 1.5 栏宽 | **120 mm ≈ 4.7 inch** |
| 双栏宽 | **183 mm ≈ 7.2 inch** |
| 字号 | 5–7 pt |
| 推荐字体 | **Helvetica / Arial** |
| 矢量首选 | PDF / EPS / AI |
| 位图 | TIFF / PNG **>= 300 DPI**；线/网格图建议 600 |
| 子图标签 | **A, B, C**（大写、加粗、左上） |

**坑**：单栏极窄（2.2 in），数据塞进单栏会被压扁，多数情况选 1.5 栏更合理。

## IEEE

涵盖 IEEE Trans 系列与 CVPR、ICCV 等会议。

| 维度 | 要求 |
|---|---|
| 单栏宽 | **3.5 inch ≈ 88.9 mm** |
| 双栏宽 | **7.16 inch ≈ 181.9 mm** |
| 字号 | 8–10 pt |
| 推荐字体 | **Times New Roman**（衬线）；图内可用 Helvetica/Arial |
| 矢量首选 | PDF / EPS |
| 位图 | **600 DPI**（线条图）/ 300 DPI（照片/灰度图） |
| 黑白可读 | **明确要求**——彩色图要在灰度下仍能区分类别 |
| 子图标签 | (a) (b) (c) 小写带括号 |

**坑**：IEEE 对黑白可读要求严格，**线型 + marker + 颜色三重冗余编码**是必须的。

## Elsevier 系列

| 维度 | 要求 |
|---|---|

| 1.5 栏宽 | 140 mm ≈ 5.5 inch |
| 双栏宽 | **190 mm ≈ 7.48 inch** |
| 字号 | 7–9 pt |
| 推荐字体 | Helvetica / Arial（无衬线） |
| 矢量首选 | EPS / PDF |
| 位图 | **300 DPI（彩色 + 灰度）**；线条图 1000 DPI |
| 子图标签 | (A) (B) (C) 大写带括号 |
| 颜色 | RGB；色觉友好 |

## 中文核心期刊通用要求

适用于 *中国科学* 系列、中文 EI 核心、CCF B/C 类等；**具体期刊以投稿须知为准**。

| 维度 | 通用要求 |
|---|---|
| 单栏宽 | **8 cm ≈ 3.15 inch** |
| 双栏宽 | **17 cm ≈ 6.7 inch** |
| 字号 | 中文 6 号（≈8 pt）/ 小 5 号（≈9 pt） |
| 字体 | **中文宋体 + 西文/数字 Times New Roman** 混排 |
| 矢量 | EPS / PDF（部分接受 TIFF） |
| 位图 | **>= 600 DPI**（线条图）/ 300 DPI（照片） |
| 颜色 | 部分期刊只接受黑白图，投稿须知必看 |
| 子图标签 | (a) (b) (c) 或 (甲) (乙) (丙)，与期刊样例一致 |

**坑 1**：中文期刊的 EPS 上传后预览常出方框——出图时用
`apply_publication_style(language="zh", serif_for_zh=True)` 走宋体类字体，
且导出优先 PDF 而非 EPS（EPS 对 TrueType 中文支持差）。

**坑 2**：数字、变量名、单位**必须**走 Times New Roman（西文衬线），
不能用中文宋体——这是排版规范。

## 中文字体安装指南

`choose_font(language="zh")` 会按优先级查找无衬线中文字体；
`serif_for_zh=True` 时优先衬线（宋体类）：

```
无衬线：Noto Sans CJK SC > Source Han Sans SC > SimHei > Microsoft YaHei
衬线：Noto Serif CJK SC > Source Han Serif SC > SimSun > STSong
```

若检测不到任何中文字体，导出前必须安装或检查缺字，不能静默提交：

- Linux：`sudo apt install fonts-noto-cjk`（Debian/Ubuntu）或
  `sudo dnf install google-noto-sans-cjk-fonts`（Fedora/RHEL）
- macOS：`brew install --cask font-noto-sans-cjk-sc font-noto-serif-cjk-sc`；
  系统自带 PingFang SC / Songti SC 已够用
- Windows：下载 Noto CJK 并“为所有用户安装”；系统自带 SimHei / SimSun /
  Microsoft YaHei 最低限度也够用

安装后刷新 matplotlib 字体缓存：

```bash
python -c "import matplotlib.font_manager as fm; fm.fontManager.addfont('字体路径')"
```

## 不同期刊的提交检查工具

- **Nature**：NPP 投稿系统自动检 DPI / 尺寸 / 字号
- **IEEE**：IEEE PDF Express 检查 PDF 嵌入字体
- **Elsevier**：投稿系统 PDF Builder 重新生成 PDF
- **arXiv**：EPS/PDF 字体未嵌入会被预览渲染成方块
