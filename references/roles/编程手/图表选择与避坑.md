# 图表选择与避坑

只有在需要选择图型、审查用户指定图型或排查成图问题时加载本文件。先看数据结构和论证目标，再考虑风格。

本文件的“决策三轴”“同一批数据不同论点”“何时该拆图”等框架吸收自
scipilot-figure-skill 的 chart_selection.md 与 viz_pitfalls.md
（MIT License, Copyright (c) 2026 Haojae）。

## 选图四问

1. 图要表达分布、比较、关系、趋势、构成、空间结构，还是模型性能？
2. 变量是连续、分类、有序、时间、空间还是矩阵？点之间是否真的存在连续关系？
3. 每组样本量、缺失、偏态、异常值和重复测量结构如何？
4. 需要展示原始观测、汇总统计、不确定性，还是三者同时展示？

## 决策三轴

每次画图前再问三个问题：

### 轴 1：变量数量与类型

| 组合 | 变量结构 |
|---|---|
| 1×连续 | 看分布 |
| 1×分类 | 看占比 |
| 1×分类 + 1×连续 | 看组间比较 |
| 2×连续 | 看关系 |
| 1×时间 + 1×连续 | 看趋势 |
| 多个连续 | 看相关 |
| 二维矩阵（n×m 数值） | 看模式 |
| 嵌套分组（A 下分 B，B 下分 C） | 看层次 |

### 轴 2：想表达什么（论证意图）

**这是最容易被忽略的一轴。** 同样的数据，论证目标不同，图就不同。

- **分布** — “这组数据长什么样” → 直方图 / KDE / 箱线
- **比较** — “A 比 B 高 / 低 / 不同” → 箱线 / 柱状（带误差）/ 小提琴
- **关系** — “X 越大 Y 越大” → 散点 + 回归
- **趋势** — “随时间/剂量变化” → 折线 + 误差带
- **构成** — “总和被分成几份” → 堆叠柱状（**不要饼图**）
- **相关** — “哪些变量之间相关” → 相关性热力图 / pairplot
- **差异** — “组间差异是否显著” → 箱线 + 显著性标注
- **不确定性** — “估计有多准” → 误差棒 / 置信带

### 轴 3：数据规模

| 样本量 | 建议 |
|---|---|
| 每组 n ≥ 30 | 箱线、柱状（带误差）、小提琴都可以；分布稳定 |
| 每组 10 ≤ n < 30 | 优先箱线/小提琴；柱状必须叠加 stripplot 显示原始点 |
| 每组 3 ≤ n < 10 | **强烈建议**直接散点/stripplot；箱线慎用（四分位估计不可靠） |
| 每组 n < 3 | **不要画箱线/小提琴**——统计估计无意义。直接展示每个点 |
| 数据总数 > 10⁴ | 散点用 alpha=0.1-0.3 防 overplotting，或改用 hexbin/2D KDE |

## 数学建模场景速查

| 任务 | 推荐图型 | 必须补充的信息 |
|---|---|---|
| 单变量分布 | 直方图/KDE、ECDF、箱线或小提琴并叠加原始点 | n、分箱或核参数、异常值规则 |
| 分组比较 | 点图、箱线/小提琴 + 原始点；样本充分且分布合适时可用均值 + 区间 | 中心统计量、区间类型、检验与效应量 |
| 两连续变量关系 | 散点 + 合理拟合与区间；大样本用透明度、hexbin 或密度 | 拟合假设、相关/回归统计、异常点处理 |
| 时间或剂量趋势 | 折线/阶梯图 + 区间；重复测量可增加个体轨迹候选图 | 时间顺序、聚合方式、区间定义 |
| 构成比例 | 排序条形图、堆叠条形图或面积图 | 分母、总和约束、类别排序 |
| 相关矩阵 | 发散热力图，必要时聚类排序 | 相关系数类型、缺失处理、色标范围 |
| 优化过程 | 目标值/最优值收敛、可行率、约束残差、Pareto 前沿 | 迭代数、停止条件、可行性定义 |
| 预测模型 | 真实值-预测值、残差、校准、误差分布、时序回测 | 数据划分、指标定义、种子/折数与区间 |
| 分类模型 | 混淆矩阵、ROC/PR、阈值-指标曲线、校准曲线 | 类别不平衡、阈值、宏/微平均口径 |
| 评价/排名 | 排名点图、带权贡献图、敏感性图 | 权重来源、归一化方法、稳定性 |
| 空间/网络 | 地图、轨迹、网络结构和局部放大 | 坐标系、比例尺、方向、图例 |
| 物理模型 | 理论-实验对照、残差、参数敏感性、近似误差随条件变化 | 单位、边界条件、近似适用域 |

图型只是起点。同一批数据可以围绕不同结论生成多张候选图，不因数据重复就机械删除；但每张图必须有清楚的用途和正确的视觉语义。

## 同一批数据，不同论点 → 不同图

### 例 1：药物 A 和 B 对响应时间的影响（30 受试者 × 2 药 × 5 时间点）

| 论点 | 推荐图 | 为什么 |
|---|---|---|
| “药物 A 整体快于 B” | 箱线（x=药物，y=时间，合并所有时间点） | 把时间维度压平专注组间 |
| “A 和 B 在 t=3 分歧最大” | 折线（x=time，y=mean，hue=药物 + 误差带） | 突出时间动态 |
| “受试者个体差异极大” | spaghetti plot（每个受试者一条细线）+ 粗均线 | 把变异性可视化 |
| “AB 在 t=3 显著不同” | 配对箱线 + 显著性桥（专做 t=3） | 单点对比 + 统计标注 |

### 例 2：基因表达谱（1000 基因 × 20 样本 + 两组）

| 论点 | 推荐图 |
|---|---|
| “两组样本可分” | PCA / UMAP 散点（hue=组） |
| “哪些基因差异表达” | volcano plot（log2FC vs -log10 p） |
| “某通路的基因都上调” | 子集 heatmap（行=通路基因，列=样本） |
| “样本间整体相似度” | sample-sample 相关热力图 + 聚类 |

建模题的同类情况：同一份仿真数据，可以分别围绕“模型收敛”“参数灵敏度”“最终方案
对比”生成不同图，这正是三类候选图（raw/process/result）各自成立的依据。

## 何时该拆图

满足以下**任何一条**就该拆：

1. **维度组合数 > 12**：例如 4×4 = 16 个 panel——一张图能塞得下，但读者解读不动；
2. **x 轴标签碰撞**：x 轴分类 > 8 个，标签需要 45°+ 旋转才放得下；
3. **图例 > 6 项**：超出短期记忆容量；
4. **y 轴尺度跨数个量级 + 不能用 log**：拆成两张分量级画；
5. **想说两件事**：如“A 比 B 快”+“A 比 B 准”，是两张图。

拆图策略：按分组维度拆（hue=sex → 两个图）、按 panel 拆、按论点拆、
主图 + 补充材料。

## 主动拦截的问题

- **小样本只画均值柱**：会隐藏样本量和分布。优先展示每个观测点，并根据样本结构选择区间或非参数摘要。
- **无关量使用双 Y 轴**：轴范围可人为制造同步关系。优先拆成共享 x 的上下子图，或用关系散点图；确有物理耦合且必须双轴时说明尺度与理由。
- **离散类别被折线连接**：会暗示不存在的连续过渡。改用点图、条形图或箱线图；有序类别的引导线需在图注声明。
- **稀疏分组率被折线连成锯齿**：按周、批次或小组计算的经验比例若样本量变化大，连线会把抽样波动伪装成连续趋势。优先画点估计 + 二项分布区间，并同时给出各组 `n`；只有时间连续性和聚合口径稳定时才连线。
- **饼图、3D 柱状或装饰性三维表面**：角度和透视不利于精确比较。优先排序条形图、堆叠图、热力图或等高线图。
- **坐标截断造成视觉夸张**：条形图应有可解释的零基线；其他图若缩小范围，需保留足够边距并清楚标示截断、对数或基准。
- **少量点估计使用巨型柱状图**：三五个推荐值、排名或参数估计更适合排序点图、棒棒糖图或点 + 区间图；柱纹理和粗边框不能替代不确定性。
- **连续颜色没有 colorbar**：读者无法还原数值。增加变量名、单位和固定的 `vmin/vmax`；跨图比较时保持色标一致。
- **已标数值的 2×2 混淆矩阵仍放 colorbar**：颜色只承担辅助分组时，直接标注计数与行/列百分比即可；冗余色条会挤压主图。类别不平衡时还要给出阈值、阳性率和 PR 基线。
- **仅靠红绿或大量相近颜色区分类别**：改用色觉友好配色，并增加线型、标记或纹理。
- **所有面板机械等宽等高**：主结论和辅助证据的信息量不同却平分画布，会产生仪表盘感。先声明主面板，再按证据权重和纵横比使用非对称布局；只有同尺度、同权重比较才等分。
- **长标题和大图例抢走第一视觉焦点**：面板内默认不放标题，确需时只保留短语，完整结论写入图注；三条以内曲线优先直接标注，四至五项使用共享图外图例，更多系列考虑分面或突出主系列。
- **稠密曲线逐点使用大标记**：会形成彩色绳结并遮蔽趋势。观测点密集时取消 marker，或用 `markevery` 只标出少量代表位置。
- **特征重要性用密集纹理粗柱**：优先排序点图或细条形图，并展示跨折/重复实验的不确定性；纹理仅在灰度打印确需区分类别时稀疏使用。
- **误差与显著性来源不明**：图注必须给出 n、区间、检验、校正和比较对象；优先同时报告效应量，不能只堆星号。
- **图例、文字或面板编号遮挡/错位**：调整布局、直接标注或图外图例，重新渲染后再检查，不能只看源代码猜测。
- **导出为截图、JPEG 或低 DPI PNG**：回到绘图代码导出 SVG + 300 DPI PNG，并检查 SVG 文本可编辑。
- **显著性符号滥用**：每个组合都画 `*`、没说检验方法、没做多重比较校正、把 n=3 的
  p=0.04 当显著结论。只标与论点有关的少数对比；图注写清检验类型、校正方法与符号
  定义；小样本考虑展示效应量（Cohen's d）。
- **缺字乱码：中文 / 负号 / 特殊符号变方框**：matplotlib 默认字体不含 CJK 字符表，
  缺字只发 warning 不报错。中文图先 `apply_publication_style(language="zh")`，
  负号方框确认 `axes.unicode_minus=False`，导出前用 `audit_layout(fig)` 兜底拦截。
- **文字裁切与图例遮盖**：标题/轴标签被画布切掉、图例压在数据上。用
  `finalize_figure(fig)` 理顺版面、图例移到图外或直接标注，再 AI 读图确认。
- **多面板子图编号不对齐**：不要用各子图自己的坐标手摆 `ax.text`；统一用
  `add_panel_labels(axes, style="nature"/"ieee")`，字号、风格、对齐一次搞定。

### 图型语义边界速记

- **折线 vs 散点**：折线只在点之间有连续关系时使用（时间/剂量/序列）；
  x 是分类或无序编号时禁止连线。
- **柱状 vs 箱线**：柱状看均值 ± 误差，假设单峰近高斯；箱线看中位数 + 四分位，
  不假设分布。n 小或分布形态未知时**默认箱线 > 柱状**。
- **热力图 vs 散点矩阵**：>8 个变量用热力图；2-8 个用 pairplot 看分布更丰富。
- **饼图与 3D 图**：人眼判断角度比长度差 3 倍，3D 视角扭曲数值；占比用排序
  条形图/堆叠图，多维用热力图或等高线。
- **双 Y 轴**：两个轴尺度可任意调，视觉“重合/分歧”是作图者捏造的；量纲不同看
  趋势就拆成共享 x 的上下子图，或标准化后共轴。

若用户坚持使用存在明显误导风险的图型，先说明具体风险和可执行替代方案；用户确认后可以保留为额外候选图，但不得把它作为唯一证据，也不得隐去风险说明。

## 成图视觉检查

- 文字和符号完整，无方框、乱码、重叠或裁切；
- 图例不压住数据，长刻度仍可读；
- 多面板标签、边距、字体、颜色和共享尺度一致；
- 第一视觉焦点是核心数据关系而不是标题、图例、色条、纹理或大片空白；
- 主面板面积与证据权重匹配，辅助面板确实补充独立证据；
- 灰度下仍能靠线型、标记或明度分辨关键系列；
- 坐标范围没有切掉点、误差棒、置信带或物理边界；
- 图在论文预计尺寸下仍可读，放大和缩小都没有暴露格式错误。
