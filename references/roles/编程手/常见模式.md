## 三大可视化类别速查

每道题的图表按以下三类系统规划，可为每类生成多个候选图：

| 类别 | 目的 | 推荐图表类型 | 产出阶段 |
|------|------|-------------|---------|
| **① 原始数据可视化** | 理解数据特征，发现潜在规律 | 直方图、箱线图、密度图、热力图、散点图矩阵、折线图、堆叠柱状图 | 拿到数据后立即绘制 |
| **② 中间产物可视化** | 展示求解过程，验证模型行为 | 收敛曲线、分组柱状图、灵敏度折线、残差图、QQ图、混淆矩阵热力图、学习曲线 | 模型运行过程中绘制 |
| **③ 最终结果可视化** | 支撑核心结论，论文直接使用 | 对比柱状图、预测折线+CI、雷达图、气泡图、组合图、地图热力图 | 求解完成后绘制 |

**应用示例**（以预测类问题为例）：
| 类别 | 图表示例 |
|------|---------|
| ① 原始数据 | 原始数据时序折线图 + 各变量分布箱线图 |
| ② 中间产物 | 训练损失收敛曲线 + 各模型验证误差分组柱状图 |
| ③ 最终结果 | 预测值 vs 真实值折线图(含置信区间) + 综合误差对比柱状图 |

## 一、柱状图

### 模式 1：分组柱状图（多方法对比）

```python
def grouped_bar(ax, categories, data_dict, colors=None, xlabel='', ylabel=''):
    """
    分组柱状图：展示多方法在多指标上的对比
    data_dict = {'方法A': [val1, val2, ...], '方法B': [val1, val2, ...]}
    """
    x = np.arange(len(categories))
    n = len(data_dict)
    width = 0.8 / n
    for i, (label, values) in enumerate(data_dict.items()):
        offset = (i - n/2 + 0.5) * width
        bars = ax.bar(x + offset, values, width, label=label,
                      color=colors[i] if colors else None,
                      edgecolor='white', linewidth=0.5)
    ax.set_xticks(x)
    ax.set_xticklabels(categories)
    ax.set_xlabel(xlabel)
    ax.set_ylabel(ylabel)
    ax.legend(frameon=False)
    return ax
```

**适用场景**：多方法在同一指标上的对比、不同方法在不同指标上的表现。

### 模式 2：堆叠柱状图（组成结构）

```python
def stacked_bar(ax, categories, parts, labels, colors, xlabel='', ylabel=''):
    """
    堆叠柱状图：展示各部分的组成结构
    parts = [ [part1_val1, part1_val2, ...], [part2_val1, part2_val2, ...] ]
    """
    x = np.arange(len(categories))
    bottom = np.zeros(len(categories))
    for i, (part, label) in enumerate(zip(parts, labels)):
        ax.bar(x, part, bottom=bottom, label=label,
               color=colors[i], edgecolor='white', linewidth=0.5)
        bottom += np.array(part)
    ax.set_xticks(x)
    ax.set_xticklabels(categories)
    ax.set_xlabel(xlabel)
    ax.set_ylabel(ylabel)
    ax.legend(frameon=False)
    return ax
```

**适用场景**：成本构成、市场份额、资源分配比例。

### 补充模式：少量点估计 + 区间

推荐时点、参数估计和少量方案得分不应默认画成粗大柱状图。点和区间更节省墨水，也允许合理缩放坐标范围：

```python
def estimate_dot(ax, labels, values, lower=None, upper=None,
                 xlabel='', color=PALETTE['primary']):
    y = np.arange(len(labels))
    if lower is None or upper is None:
        ax.plot(values, y, 'o', color=color, markersize=3.5)
    else:
        xerr = np.vstack([np.asarray(values) - np.asarray(lower),
                          np.asarray(upper) - np.asarray(values)])
        ax.errorbar(values, y, xerr=xerr, fmt='o', color=color,
                    markersize=3.5, capsize=2, linewidth=1)
    ax.set_yticks(y, labels)
    ax.set_xlabel(xlabel)
    ax.invert_yaxis()
    return ax
```

**适用场景**：分组推荐孕周、排名得分、估计参数、敏感性指标。区间必须来自代码计算；没有可辩护区间时只画点，不伪造误差棒。

## 二、折线图

### 模式 3：趋势 + 置信区间

```python
def trend_with_ci(ax, x, y, lower_ci, upper_ci, color='#0F4D92', label=''):
    """折线图 + 已按明确统计方法计算的置信区间"""
    ax.plot(x, y, color=color, linewidth=1.5, label=label)
    ax.fill_between(x, lower_ci, upper_ci, color=color, alpha=0.12)
    ax.set_xlabel('迭代次数')
    ax.set_ylabel('损失值')
    ax.legend(frameon=False)
    return ax
```

**适用场景**：收敛曲线、时间序列预测、误差随参数变化。

### 模式 4：多线对比

```python
def multi_line(ax, x, data_dict, xlabel='', ylabel=''):
    """多线对比：多条曲线在同一坐标系中对比"""
    for label, (y, color) in data_dict.items():
        ax.plot(x, y, color=color, linewidth=1.5, label=label)
    ax.set_xlabel(xlabel)
    ax.set_ylabel(ylabel)
    ax.legend(frameon=False)
    return ax
```

**适用场景**：多算法收敛速度对比、不同参数设置下的效果对比。

## 三、热力图

### 模式 5：相关性 / 混淆矩阵热力图

```python
def make_heatmap(ax, data, cmap='RdBu_r', vmin=None, vmax=None,
                 annot=True, fmt='.2f', cbar_label='', show_colorbar=True):
    """热力图：展示矩阵数据，可选单元格标注"""
    im = ax.imshow(data, cmap=cmap, aspect='auto', vmin=vmin, vmax=vmax)
    if show_colorbar:
        cbar = ax.figure.colorbar(im, ax=ax, shrink=0.8)
        cbar.set_label(cbar_label)
    if annot:
        for i in range(data.shape[0]):
            for j in range(data.shape[1]):
                rgba = im.cmap(im.norm(data[i, j]))
                color = luminance_text_color(rgba[:3])
                ax.text(j, i, f'{data[i,j]:{fmt}}', ha='center', va='center',
                       fontsize=8.5, color=color)
    ax.set_xticks(range(data.shape[1]))
    ax.set_yticks(range(data.shape[0]))
    return ax
```

**适用场景**：特征相关性矩阵、混淆矩阵、Z-score 偏差热图。

相关矩阵、连续误差矩阵和 Z-score 热图需要带单位或统计含义的 colorbar。已在格内直接标注计数/比例的 `2×2` 混淆矩阵使用 `show_colorbar=False`，避免冗余色条挤压画布。

**Z-score 热图的特殊配置**：
```python
z = (data - data.mean(axis=0)) / data.std(axis=0)
im = ax.imshow(z, cmap='RdBu_r', aspect='auto', vmin=-2.5, vmax=2.5)
```

### 模式 6：气泡图（三维数据）

def bubble_scatter(ax, x, y, size, color='#0F4D92', xlabel='', ylabel=''):

### 模式 7：散点 + 拟合线 + 象限标注

```python
def scatter_with_fit(ax, x, y, xlabel='', ylabel=''):
    """散点图 + 拟合线 + 象限分割"""
    ax.scatter(x, y, s=9, c=PALETTE['primary'], alpha=0.55,
               edgecolor='white', linewidth=0.3)
    # 拟合线
    z = np.polyfit(x, y, 1)
    p = np.poly1d(z)
    ax.plot(x, p(x), '-', color=PALETTE['contrast'], linewidth=1.2)
    # 象限分割线
    ax.axvline(np.median(x), lw=0.8, ls='--', color=PALETTE['neutral'], alpha=0.5)
    ax.axhline(np.median(y), lw=0.8, ls='--', color=PALETTE['neutral'], alpha=0.5)
    ax.set_xlabel(xlabel)
    ax.set_ylabel(ylabel)
    return ax
```

**适用场景**：相关性分析、Pareto 前沿、分类结果展示。

## 五、分布图

### 模式 8：箱线图

```python
def make_boxplot(ax, data, labels, colors=None, ylabel=''):
    """箱线图：展示数据分布"""
    bp = ax.boxplot(data, labels=labels, patch_artist=True,
                    widths=0.6, showmeans=True)
    if colors:
        for patch, color in zip(bp['boxes'], colors):
            patch.set_facecolor(color)
            patch.set_alpha(0.7)
    ax.set_ylabel(ylabel)
    ax.set_xticklabels(labels)
    return ax
```

**适用场景**：多组数据分布对比、误差分析、稳定性检验。

### 模式 8b：箱线/小提琴 + 原始点叠加（首选，n<30 必用）

小组（n<10）或分布形态未知时，均值柱状会掩盖分布。箱线/小提琴 + stripplot
叠加原始点是审稿人最认可的默认组合：

```python
import seaborn as sns

fig, ax = plt.subplots()
sns.boxplot(data=df, x="group", y="value", hue="condition",
            palette=[PALETTE["primary"], PALETTE["secondary"]],
            showfliers=False, width=0.6, linewidth=0.8, ax=ax)
sns.stripplot(data=df, x="group", y="value", hue="condition",
              palette=[PALETTE["primary"], PALETTE["secondary"]],
              dodge=True, size=2.5, alpha=0.6,
              edgecolor="black", linewidth=0.3, ax=ax, legend=False)
ax.set(xlabel="", ylabel="得分（单位）")
ax.legend(frameon=False)
# 图注必须写：箱线=中位数、IQR、1.5×IQR 须线；点为原始观测；n 各多少
```

小提琴图把 `boxplot` 换成 `violinplot(inner=None, cut=0)` 即可；n<10 时
密度估计不可靠，建议直接用箱线。

### 模式 8c：显著性桥

```python
def sig_bracket(ax, x1, x2, y, height, text, fontsize=8):
    ax.plot([x1, x1, x2, x2], [y, y + height, y + height, y],
            color="black", linewidth=0.6)
    ax.text((x1 + x2) / 2, y + height, text, ha="center",

```

图注必须写检验类型、校正方法（Bonferroni/FDR）与符号定义；只标与论点有关的

## 六、分类与决策图

### 补充模式：PR 曲线与基线

类别不平衡时，PR 曲线必须显示阳性率基线；稠密曲线不逐点使用 marker：

```python
def pr_curve(ax, recall, precision, prevalence, label, color):
    ax.plot(recall, precision, color=color, linewidth=1.1, label=label)
    ax.axhline(prevalence, color=PALETTE['neutral'], linestyle='--',
               linewidth=0.8, label=f'阳性率基线 {prevalence:.2f}')
    ax.set(xlabel='召回率', ylabel='精确率', xlim=(0, 1), ylim=(0, 1))
    return ax
```

多折交叉验证优先展示平均曲线及区间，并在图注写明折数、划分方式和种子。系列超过五项时拆分任务或突出主模型，不把长图例压在数据区。

### 补充模式：紧凑型 2×2 混淆矩阵

```python
def confusion_2x2(ax, matrix, labels=('阴性', '阳性')):
    matrix = np.asarray(matrix)
    image = ax.imshow(matrix, cmap='Blues', aspect='equal')
    for row in range(2):
        row_total = matrix[row].sum()
        for column in range(2):
            ratio = matrix[row, column] / row_total if row_total else 0
            rgba = image.cmap(image.norm(matrix[row, column]))
            ax.text(column, row, f'{matrix[row, column]}\n{ratio:.1%}',
                    ha='center', va='center',
                    color=luminance_text_color(rgba[:3]), fontsize=8)
    ax.set_xticks([0, 1], [f'预测{item}' for item in labels])
    ax.set_yticks([0, 1], [f'真实{item}' for item in labels])
    return ax
```

格内已有计数和行百分比，因此不再添加 colorbar。图注另写阈值、验证划分和核心指标。

### 补充模式：相关矩阵与散点矩阵

连续变量 ≤ 8 用 pairplot，> 8 用相关性热力图；对称矩阵画一半更易读：

```python
import seaborn as sns

corr = df[numeric_cols].corr(method="pearson")

fig, ax = plt.subplots()
sns.heatmap(corr, mask=mask, cmap="RdBu_r", vmin=-1, vmax=1, center=0,
            annot=True, fmt=".2f", annot_kws={"fontsize": 8.5},
            cbar_kws={"label": "Pearson r", "shrink": 0.7},
            linewidths=0.5, linecolor="white", square=True, ax=ax)
ax.tick_params(labelsize=6)
```

双向数据用发散色图 + `center=0`；单向数据用 `viridis`/`magma`；禁止
`rainbow`/`jet`。

### 模式 11：色深对比判断

```python
def luminance_text_color(color):
    """根据十六进制色或 0-1 RGB 背景色返回高对比文字颜色"""
    if isinstance(color, str):
        c = color.lstrip('#')
        r, g, b = (int(c[i:i+2], 16) / 255 for i in (0, 2, 4))
    else:
        r, g, b = color[:3]
    return 'white' if 0.299*r + 0.587*g + 0.114*b < 0.5 else '#333333'
```

## 七、图表类型速查

| 你想展示什么 | 用这个模式 | 效果 |
|-------------|-----------|------|
| 多方法多指标对比 | 模式 1：分组柱状图 | 一目了然谁好谁差 |
| 某总量的组成结构 | 模式 2：堆叠柱状图 | 看出各部分占比 |
| 随时间的变化趋势 | 模式 3：趋势+CI | 趋势清晰，不确定性可见 |
| 多方法收敛速度 | 模式 4：多线对比 | 快慢分明 |
| 变量间相关性 | 模式 5：热力图 | 大片红色=强相关 |
| 三个变量的关系 | 模式 6：气泡图 | 大小=第三维 |
| x和y是否相关 | 模式 7：散点+拟合 | 趋势线一目了然 |
| 数据分布是否稳定 | 模式 8：箱线图 | 离群值无所遁形 |
| 组间分布对比（n<30） | 模式 8b：箱线/小提琴 + 原始点 | 分布与样本量同时可见 |
| 组间差异是否显著 | 模式 8c：显著性桥 | 与检验、校正、n 一并交代 |
| 单变量分布形态 | 模式 8d：直方图+KDE+rug | 双峰、偏态一目了然 |
| 多图图例太多 | 模式 9：图例专轴，或直接标注 | 清爽不遮挡 |
| 少量参数或推荐值 | 少量点估计 + 区间 | 避免巨型柱和非零基线误导 |
| 类别不平衡分类 | PR 曲线 + 阳性率基线 | 性能与基线关系明确 |
| 2×2 分类计数 | 紧凑混淆矩阵 | 无冗余 colorbar，计数与比例同时可读 |
| 多连续变量相关 | 相关矩阵 / 散点矩阵 | ≤8 列 pairplot，>8 列热力图 |
| 少量点位的均值±误差 | 模式 12：误差棒图 | 剂量/时间点位对比 |
