# 编程手质检清单

形式合规项吸收自 scipilot-figure-skill 的 publication_checklist.md
（MIT License, Copyright (c) 2026 Haojae）。语义避坑交叉检查见
《图表选择与避坑.md》。

- [ ] 只读取输入和建模手两个 Markdown 产物，未覆盖它们。
- [ ] 仅检查所选模型和功能需要的 Python 包或 MATLAB 工具箱。
- [ ] Python/MATLAB 代码已真实运行，退出状态和异常已检查。
- [ ] 约束、边界、量纲和验证指标正确。
- [ ] 在全量计算和正式出图前，独立质检 Subagent 已执行 `P1` 最小命令并返回 `PASS`。
- [ ] 逐题模式（如启用）：每题已依次执行 `P1-qN`、全量计算与出图、`P2-qN`，未跳过或混题并行。
- [ ] 逐题模式：逐题审计传当前题 `--questions qN`，全部完成后整题审计传 `--questions q1 q2 ... qN --strict` 并返回 0。
- [ ] 逐题模式：`results/复现清单.json` 在全部题目完成后统一生成，包含各题唯一复现命令；`P2-总` 已返回 `PASS`。
- [ ] 随机种子和关键参数显式记录。
- [ ] 输入文件 SHA-256、版本和唯一复现命令已写入 `results/复现清单.json`。
- [ ] 绘图前已用 `profile_data.py` 或等价方式核对实际行列、表头、缺失、分组样本量、分布、异常值和单位；列类型识别错误已修正后重跑；删行、聚合或抽样均有数量与理由。
- [ ] 目标竞赛/期刊规范已确认：官方模板规定尺寸、字号、字体或格式时已按官方配置并记录；未规定时按《期刊规范.md》基线（单栏/双栏、自适应字号、DPI、字体）执行。
- [ ] 每张候选图已有核心结论、所属类别、证据/面板映射、统计口径和最终尺寸；图型与变量语义匹配。
- [ ] 每张图已选择叙事原型并声明主面板；不同证据权重或纵横比的面板未机械等分，互不支撑的结果未堆进同一画布。
- [ ] 已从题目分析报告列出全部子问题并规范为 `q1…qN`；已生成 `raw_qN_*`、`process_qN_*`、`result_qN_*` 三类候选图，每类至少 3 张逻辑图、合计至少 9 张，且每个子问题在三类中各至少 1 张。同一图的多格式输出按 1 张计数，允许继续多生成，不机械删除有效备选视角。
- [ ] 图采用克制的 Nature/SCI 出版风格基线，无默认网格、装饰性 3D、`rainbow`/`jet` 色图或无说明的误导尺度；官方模板要求已优先应用。
- [ ] 同一变量跨图颜色语义一致，并使用色觉友好颜色及线型/标记等冗余编码。
- [ ] 第一视觉焦点是核心数据关系，不是长标题、大图例、密集纹理、冗余 colorbar 或大片空白；完整论述已移到图注。
- [ ] 稠密曲线未逐点使用大标记；图例采用直接标注、单个共享图例或合理分面，面板内没有相同语义的重复图例。
- [ ] 柱状图从零开始；少量点估计优先使用点图/区间图；离散或样本量不稳定的经验率没有被折线伪装成连续趋势。
- [ ] 每组 n<10 时未用裸均值柱状图；n<30 时箱线/小提琴叠加了原始点；双峰、偏态和异常值已按报告结论处理并交代。
- [ ] 无双 Y 轴误导；无饼图/3D 柱/3D 饼/3D 表面；连续色阶均有带变量名和单位的 colorbar，跨图色标范围一致。
- [ ] 显著性标注只标与论点有关的对比，图注写明检验类型、校正方法与符号定义；小样本考虑了效应量。
- [ ] 面板内默认无标题、无面板编号，只保留数据；坐标轴、单位、图例、colorbar 和数据范围正确；已标数值的 2×2 小矩阵没有冗余 colorbar，图例与标注不遮挡数据。
- [ ] 置信区间和统计量由代码计算，无硬编码 p 值；图注说明 n、中心统计量、区间/离散程度、检验和校正。
- [ ] 默认每张图只输出至少 300 DPI 的 PNG；需要时追加 SVG（可编辑文本）或灰度预览；HTML 相对路径正确。
- [ ] 产生 PDF 时确认嵌入 TrueType 字体（fonttype 42），无 Type 3；`figure_audit.py` 的 PDF 检查已通过或已说明 pypdf 缺失。
- [ ] 中文图已配置中文字体；中文期刊混排按“宋体正文 + Times New Roman 数字”执行；负号无方框（`axes.unicode_minus=False`）；中文期刊优先 PDF 而非 EPS。
- [ ] 导出未用 `bbox_inches="tight"` 偷换最终尺寸；PNG 元数据中的实际英寸尺寸与图表契约一致。
- [ ] `python "<SKILL_ROOT>/scripts/figure_audit.py" "<PROJECT_ROOT>/figures" --questions q1 q2 ... qN --strict` 已列出全部子问题并返回 0；审计结果未被人工忽略。
- [ ] 已按《视觉回审.md》完成闭环：`render_preview` 渲染预览、`audit_layout` 程序自检无 `FAIL`，并实际打开 PNG（存在灰度预览时一并打开）逐项核对 8 项清单（缺字、裁切、遮盖、面板对齐、间距、灰度可辨、数据完整、跨图一致）；问题已通过修改源代码后重跑解决。
- [ ] 所有新文件位于 `PROJECT_ROOT`，未写入 `SKILL_ROOT`。
- [ ] 代码、结果、图和复现清单冻结后，独立质检 Subagent 已执行 `P2` 并返回 `PASS`。
- [ ] `P1`、`P2` 通过后相关产物未发生未经复验的实质变化。
