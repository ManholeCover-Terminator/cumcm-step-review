# 视觉自检闭环：程序自检 + AI 读图 + 回改

本文件吸收自 scipilot-figure-skill 的 visual_review.md
（MIT License, Copyright (c) 2026 Haojae），接入编程手已有的
`plot_style.audit_layout()` 与新增的 `plot_style.render_preview()`。

普通绘图流程画完就结束，中文方框、文字被裁、图例压住数据、子图编号乱放
全留到投稿才被发现。本文件定义一套出图后的闭环：

```
绘制 → ① 渲染 PNG 预览 → ② 程序自检(audit_layout) → ③ AI 读图自检
                                                        ↓ 发现问题
        ⑤ 通过 ← ④ 回到对应步骤改图 → 重新渲染 → 再读图 ←┘
```

## 为什么必须“渲染成 PNG 再让 AI 看”

- 矢量 PDF/SVG 没法直接“看”像素层面的重叠和遮挡——必须先栅格化成 PNG；
- 程序能查有限：缺字、越界、刻度相交这类**确定性**问题程序能抓，
  但“图例正好压在一簇数据点上”“两条标注文字叠在一起”“配色看着发灰分不开”
  这类**感知性**问题，只有把图当成图像看才发现。

## 分工：程序自检 vs AI 读图

| 层 | 工具 | 负责抓 |
|---|---|---|
| 程序自检 | `plot_style.audit_layout(fig)` | 缺字乱码、文字越界裁切、刻度标签重叠（确定性） |
| AI 读图 | 本文件清单 + 打开 PNG 预览 | 图例压数据、标注重叠、子图标签对齐、配色/灰度可分、整体观感（感知性） |

两层都要过。程序 PASS 不代表图就好；AI 读图才是终检。

## 标准操作流程

### 第 1 步：渲染预览

在正式导出**之前**，把刚画好的 Figure 渲染成 PNG 预览：

```python
from utils.plot_style import audit_layout, render_preview

preview = render_preview(fig, "figures/_preview.png", dpi=150)
```

用 150 dpi：足够看清文字与重叠，又不会太大拖慢读图。发现问题还能在源头改。

### 第 2 步：程序自检

```python
issues = audit_layout(fig)
for severity, message in issues:
    print(f"[{severity}] {message}")
```

任何 `FAIL`（几乎只会是缺字乱码）**必须先修**再继续。`WARN`（裁切/重叠）
记下来，到第 3 步读图时重点确认。

### 第 3 步：AI 读图自检（关键）

实际打开 `figures/_preview.png`，**逐条**对照下面的清单核对，不要扫一眼说
“看起来不错”。清单共 8 项：

1. **乱码 / 方框**：中文有没有变成 □□□？负号、`±`、`×`、`μ`、`Δ`、希腊字母、
   上下标有没有缺字？
2. **文字被裁切**：标题、x/y 轴标签、图例、数值标注有没有被画布四边切掉？
   旋转后的长刻度标签底部有没有出界？
3. **文字遮盖 / 重叠**：图例有没有压住数据？显著性标注、数值标签之间有没有互叠？
   x 轴刻度标签有没有挤成一团？
4. **子图编号对齐**（多面板必查）：a/b/c/d 是否横看一条线、竖看一条线？
   字号、加粗、风格是否一致（不能有的 `a` 有的 `(a)`）？
5. **子图间距 / 互相侵入**：子图之间有没有重叠？某个子图的 y 轴标签有没有伸进
   左边邻居？colorbar 有没有压住数据？
6. **配色与灰度**：各类别颜色能区分吗？有没有红绿对比？灰度版还能分开吗？
   分不开 → 加线型/marker 冗余编码。
7. **数据完整性**：数据点/曲线/误差棒有没有被坐标轴范围切掉？最高的柱、最外的点
   是否在框内可见？
8. **跨子图一致性**：同一变量在多个子图里是否同色、同标记、同量纲？共享含义的
   坐标轴范围是否一致？

### 第 4 步：回改对应表

发现问题回到对应环节改，**不要在预览图上手动 P 图**：

| 读图发现 | 回改动作 |
|---|---|
| 中文/符号缺字方框 | `apply_publication_style(language="zh")`；负号方框确认 `axes.unicode_minus=False`（样式基线已默认关闭） |
| 文字被裁切 | `finalize_figure(fig)` 理顺版面；标题过长则换行/缩短 |
| 图例压住数据 | 图外图例 `ax.legend(bbox_to_anchor=(1.02, 1), frameon=False)`；或直接末端标注 |
| 标注文字互相叠 | 调整 `xytext` 偏移；减少标注数量（只标关键的） |
| x 轴刻度重叠 | `ax.tick_params(axis='x', rotation=30)`；减少刻度数；缩短标签 |
| 子图标签不对齐 | 用 `add_panel_labels(axes, style="nature"/"ieee")` 统一重打 |
| 子图互相重叠 | `finalize_figure(fig)` 或建图时用 `publication_subplots()` |
| 配色不可区分/灰度糊 | 换色觉友好配色 + 加线型/marker |
| 数据被切掉 | 放宽 `set_xlim/set_ylim`，或 `ax.margins(0.05)` |

### 第 5 步：重新渲染，再读图

改完回到第 1 步重新渲染并再读一次，循环直到：程序自检无 `FAIL`，且
读图清单 8 项全部通过，**或**剩余问题已明确告知用户并获其接受。

## 循环纪律

- **每改一处就重渲一次**——不要一次改五处然后猜结果，看不到就是没验证；
- **最多 3 轮**：3 轮还过不了，多半是图型选错了（回《图表选择与避坑.md》重选）
  或数据维度太多（拆图）；
- **留痕**：把每轮发现的问题和改法简要记入工作记录，让复现清单可追溯。

## 一个完整示例

```python
import matplotlib.pyplot as plt
from utils.plot_style import (
    add_panel_labels,
    apply_publication_style,
    audit_layout,
    export_figure,
    finalize_figure,
    publication_subplots,
    render_preview,
)

apply_publication_style(language="zh", width="double", journal="nature")
fig, axes = publication_subplots(2, 2, width="double", aspect=0.72)
# ... 在 axes 上作图 ...

# —— 自检闭环 ——
finalize_figure(fig)                       # 兜底理顺版面
add_panel_labels(axes, style="nature")     # a b c d 对齐
render_preview(fig, "figures/_preview.png")  # 渲 PNG
issues = audit_layout(fig)                 # 程序自检
# 然后：打开 figures/_preview.png，对照上面 8 项清单逐条核对
# 有问题 → 按回改表改 → 重渲 → 再读；全过后再正式导出：

outputs = export_figure(fig, "figures/result_q1_main")
```

**记住**：正式导出是最后一步，在读图清单全过之后。把问题挡在导出之前。
