## 一份报告长什么样

从 `PROJECT_ROOT` 执行（`SKILL_ROOT` 指 cumcm-step-review 技能根目录）：

```powershell
python "<SKILL_ROOT>/scripts/profile_data.py" `
  "<PROJECT_ROOT>/data/input.csv" --group group --group condition
```

输出四个核心区块：

1. **列信息** — 每列的类型、样本量、缺失率、关键统计
2. **分组结构** — 分组样本量的最小/中位/最大
3. **相关性** — 数值列之间的 Pearson r（按 |r| 排序）
4. **警告 + 初步图型建议** — 自动提示与图型起点

## 列类型识别规则

`profile_data.py` 把列分成 6 种类型：

| 类型 | 识别规则 | 画图含义 |
|---|---|---|
| `continuous` | numeric，唯一值 > 7 或含小数 | y 轴默认走它；做散点、折线、箱线 |
| `ordinal` | numeric，唯一整数值 ≤ 7（如 Likert 1-5） | 横轴可走，但**别连折线**（除非确定有序） |
| `categorical` | object/categorical，唯一值 ≤ 30 且类别比 < 0.5 | x 轴 / hue 走它 |
| `boolean` | bool 或全 0/1 | 拆成 2 组对比 |
| `datetime` | datetime，或前 10 个非空值可解析为日期 | 时间轴；折线首选 x |
| `text` | object，唯一值多到不像分类 | 一般是 ID/笔记类，**不画** |

**坑**：自动识别偶尔出错。实验编号是数字（1-10）会被认成 ordinal 但你想当分类；
数字类别标签（0=control, 1=drug A）同理——手动 `df['col'] = df['col'].astype(str)`。
跑完报告**先看类型识别对不对**，错了改类型再重跑。

## 样本量的影响

### 阈值

| 每组 n | 该用什么图 | **不能**用什么图 |
|---|---|---|
| n < 3 | **直接列每个点**（dot plot） | 均值柱状、箱线、小提琴（统计估计无意义） |
| 3 ≤ n < 10 | stripplot / 蜂巢散点 / dot plot | 均值柱状（掩盖太多）；箱线慎用 |
| 10 ≤ n < 30 | **箱线 + 叠加 stripplot** | 仅画均值柱状（**严禁**） |
| n ≥ 30 | 箱线 / 小提琴 / 带误差柱 都可 | — |

### 为什么阈值这么定

- n=3 时箱线的四分位只有 1 个点撑，所谓“中位数/分位”没有意义；
- n=5 的均值标准误 ≈ SD/√5 ≈ SD×0.45，置信区间几乎和原始分布一样宽，画误差棒反而误导；
- n<10 不画原始点等于把数据信息扔掉一半，审稿人直接质疑。

报告里出现“存在 n<10 的组”警告时，立刻把图型从“均值柱”切到“箱线 + stripplot”。

## 分布形态的影响

报告对每个连续变量给出 mean、sd、range、skew 与异常值提示。

### 偏度（skew）

| skew | 含义 | 决策 |
|---|---|---|
| \|skew\| < 0.5 | 大致对称 | 均值 ± SD 可信；箱线、小提琴都合适 |
| 0.5 ≤ \|skew\| < 1 | 中度偏 | 优先**中位数 ± IQR**；柱状图改箱线 |
| \|skew\| ≥ 1 | 高度偏 | 必须箱线 / 小提琴；考虑**对数变换**或对数 y 轴 |

偏态分布不画均值柱：均值被极值拉走，“均值±SD”会画出超出数据真实范围的下界。

### 跨量级 → 对数轴

报告提示“跨数个量级”时（最大值/最小值 > 100 且全正）用对数轴，例如剂量
0.1/1/10/100 → log x 轴；蛋白丰度跨 6 个数量级 → log y 轴。

### 异常值

`outliers=n (IQR)` 表示 IQR 法（Q1-1.5·IQR ~ Q3+1.5·IQR 之外）有 n 个点。
处理三选一（**必须在图注交代选择**）：

1. **展示**：画出来让读者看到分布全貌（推荐）；
2. **标注**：保留但加 annotation 说明（如“sample #17, instrument error”）；
3. **剔除**：必须有明确方法学理由（如“明显录入错误”），**不能因为不喜欢就剔**。

绝对禁止：偷偷删掉异常点不报告。

## 分组结构的影响

### 单分组 vs 多分组

| 分组维度 | 映射建议 |
|---|---|
| 单维度（group: A/B/C） | x 轴 |
| 双维度（group × condition） | x 轴 + hue 颜色 |
| 三维度（group × condition × sex） | x 轴 + hue + 子图（facet） |
| 四维度+ | **拆图**或选子集；视觉通道用尽了 |

### 嵌套 vs 交叉

- **交叉**（每个组合都有样本）：`groupby(['A','B'])` 所有组合都有；
- **嵌套**（B 在 A 内独立，如 patient 嵌套在 hospital 内）：hospital 之间的
  patient ID 不可比，不能当交叉处理。

### 平衡 vs 不平衡

- min ≈ max：平衡，统计推断方便；
- min ≪ max：不平衡，需要 mixed model 或权重；画图时**不要直接画“组均值”**误导观感。

## 相关性 / 多重共线性的提示

`相关性` 区按 |r| 排序列出前 10 对。

1. **高度相关的列**（|r| > 0.7）：画散点时互为冗余，不要俩都做 x 轴或都做 hue；
2. **多重共线性预警**：做回归/PCA 时强相关变量让模型不稳，画 pairplot 看清楚；
3. **决定 pairplot 子集**：20 列全 pairplot 没法看，用 r 排序选 top 5-8 个变量。

### 相关性陷阱

- **辛普森悖论**：整体相关 vs 分组内相关方向相反——散点必须分组着色看；
- **非线性相关**：Pearson 只测线性，r=0.1 别下“无关”结论，先画散点。

## 缺失值与异常值

| 缺失率 | 处理 |
|---|---|
| < 5% | 默认忽略；画图时 dropna 即可 |
| 5-20% | 在图注里交代“n=89 of 100 (11% missing)” |
| > 20% | **不能默默忽略**——考虑是否分组导致系统性缺失 |

缺失模式：MCAR 可 dropna；MAR 分组分析要分别处理；MNAR 缺失本身可能是信号，
考虑画“缺失率”专图。

## 从报告到画图决策的流程

```
profile_data.py 输出报告
        ↓
1. 看列信息：类型对不对？错的列 astype 修正后重跑
        ↓
2. 看分组结构：n<10 → 箱线+stripplot；n<3 → 直接列点
        ↓
3. 看偏度：skew>1 → 箱线/小提琴 + 考虑 log 轴
        ↓
4. 看分组维度组合：>12 → 拆图，不要硬塞
        ↓
5. 看相关性：决定散点 hue/style 与 pairplot 子集
        ↓
6. 看警告：每条都处理掉
        ↓
7. 看初步图型建议：作为起点，最终决定结合论证目标
        ↓
查《图表选择与避坑.md》把“数据形态”和“想表达什么”对上，定最终图型
```

**记住**：`profile_data.py` 给的是数据的事实，《图表选择与避坑.md》把事实和
论点结合起来选图，二者缺一不可。
