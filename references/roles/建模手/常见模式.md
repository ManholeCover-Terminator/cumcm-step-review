# 建模常见模式

数学建模中反复出现的模型组合模式，按问题类型分类整理。

---

## 一、优化类问题常见模式

### 模式 1：线性/整数规划 → 灵敏度分析

| 要素 | 说明 |
|------|------|
| **适用场景** | 资源分配、生产调度、投资组合 |
| **主模型** | 线性规划 / 整数规划 |
| **辅助分析** | 灵敏度分析（改变约束右端项或目标系数） |
| **输出** | 最优解 + 影子价格 + 灵敏度范围 |
| **证据链** | 最优解"是什么" + 灵敏度"多稳" |
| **备选方案** | 目标规划（多目标时）、动态规划（分阶段时） |

### 模式 2：启发式算法 → 对比验证

| 要素 | 说明 |
|------|------|
| **适用场景** | 大规模 NP-hard 问题（TSP、VRP、调度） |
| **主模型** | 遗传算法 / 模拟退火 / 粒子群 |
| **辅助分析** | 与精确解（小规模）或文献结果对比 |
| **输出** | 近优解 + 收敛曲线 + 多算法对比 |
| **证据链** | 启发式"找到了" + 对比"证明了有效性" |
| **备选方案** | 不同启发式算法之间互为备选 |

### 模式 3：多目标优化 → Pareto 分析

| 要素 | 说明 |
|------|------|
| **适用场景** | 成本 vs 质量、效率 vs 公平等多目标权衡 |
| **主模型** | NSGA-II / MOEA / 加权和法 |
| **辅助分析** | Pareto 前沿可视化 + TOPSIS 选最优折衷 |
| **输出** | Pareto 前沿图 + 推荐折衷方案 |
| **证据链** | 多目标"全面了" + TOPSIS"选出了" |

## 二、预测类问题常见模式

### 模式 4：单一预测 → 误差检验

| 要素 | 说明 |
|------|------|
| **适用场景** | 数据量小、趋势明显 |
| **主模型** | 灰色预测 GM(1,1) / 线性回归 / 指数平滑 |
| **辅助分析** | 残差检验 + 后验差检验 + 相对误差 |
| **输出** | 预测值 + 置信区间 + 误差指标 |
| **证据链** | 预测"给出了" + 检验"可信了" |
| **备选方案** | 如果残差有模式，换 ARIMA |

### 模式 5：双模型对比或集成预测

| 要素 | 说明 |
|------|------|
| **适用场景** | 数据量充足、需要提高精度 |
| **主模型** | 从 ARIMA、LSTM、XGBoost 等候选中选择两个 |
| **辅助分析** | 两个模型误差对比；有依据时进行双模型加权 |
| **输出** | 集成预测值 + 各模型权重 + 对比表 |
| **证据链** | 单一模型"各有所长" + 集成"更好" |
| **注意** | 确保模型间有差异才有集成价值 |

### 模式 6：组合预测（串联）

| 要素 | 说明 |
|------|------|
| **适用场景** | 先分类再预测、先分解再预测 |
| **结构** | 模型A 输出 → 模型B 输入 |
| **典型组合** | 聚类→回归（先分群再分别预测）、STL 分解→ARIMA（先分解趋势+季节+残差再分别预测） |
| **证据链** | 分解"拆开了" + 分别预测"更准了" |

## 三、评价类问题常见模式

### 模式 7：赋权 + 综合评价

| 要素 | 说明 |
|------|------|
| **适用场景** | 需要确定指标权重并完成方案排序 |
| **赋权模型** | AHP 或熵权法二选一，依据专家信息和数据条件决定 |
| **评价模型** | TOPSIS / 灰色关联分析 / 模糊综合评价中选择一个 |
| **输出** | 权重 + 各方案得分排名 |
| **证据链** | 权重依据 + 综合评价结果 |
| **检查** | 权重扰动或数据变化下的排名稳定性 |

### 模式 8：DEA 效率评价

| 要素 | 说明 |
|------|------|
| **适用场景** | 多个决策单元的效率比较（银行、医院、学校） |
| **主模型** | DEA（CCR / BCC 模型） |
| **辅助分析** | 投影分析 + 规模收益分析 |
| **输出** | 效率值 + 无效单元的改进目标 |
| **证据链** | 效率"评出了" + 改进"指明了" |

## 四、综合类问题常见模式

### 模式 9：优化 + 模拟

| 要素 | 说明 |
|------|------|
| **适用场景** | 不确定性环境下的决策 |
| **结构** | 蒙特卡洛模拟生成场景 → 优化模型在每个场景下求解 → 统计结果 |
| **典型应用** | 随机规划、鲁棒优化、风险评估 |
| **输出** | 最优解的分布 + 风险指标（VaR、CVaR） |
| **证据链** | 模拟"覆盖了不确定性" + 优化"找到了稳健解" |

### 模式 10：评价 + 优化（先评后优）

| 要素 | 说明 |
|------|------|
| **适用场景** | 先评估现状再寻找改进方案 |
| **结构** | 评价模型识别薄弱环节 → 优化模型给出改进方案 |
| **典型应用** | 先 AHP 找出权重最大的因素，再优化该因素的资源配置 |
| **输出** | 评价结果 + 针对性优化方案 |
| **证据链** | 评价"找到了关键" + 优化"解决了关键" |

### 模式 11：预测 + 决策

| 要素 | 说明 |
|------|------|
| **适用场景** | 先预测趋势再做决策 |
| **结构** | 预测模型给出未来数据 → 优化模型基于预测做决策 |
| **典型应用** | 需求预测→库存优化、交通流量预测→信号灯优化 |
| **输出** | 预测值 + 基于预测的最优决策 |
| **证据链** | 预测"预见了" + 决策"应对了" |

## 五、模型组合决策树

```
题目是哪种核心类型？
├─ 优化 → 有随机性吗？
│   ├─ 是 → 模式 9（优化+模拟）
│   └─ 否 → 规模大吗？
│       ├─ 大 → 模式 2（启发式+对比）
│       └─ 小 → 模式 1（精确规划+灵敏度）
│
├─ 预测 → 有充足数据吗？
│   ├─ 是 → 需要高精度吗？
│   │   ├─ 是 → 模式 5（双模型对比或集成）
│   │   └─ 否 → 模式 4（单一预测+检验）
│   └─ 否 → 模式 4（灰色预测/小样本方法）
│
├─ 评价 → 需要客观权重吗？
│   ├─ 有数据 → 模式 7（主客观组合赋权）
│   └─ 无数据 → AHP（纯主观）
│
└─ 组合类 → 按阶段拆分
    ├─ 先预测再优化 → 模式 11
    ├─ 先评价再优化 → 模式 10
    └─ 先分类再预测 → 模式 6
```
