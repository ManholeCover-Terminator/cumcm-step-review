# 英文化工作流（美赛专用）

美赛论文使用英文撰写。当建模分析和代码实现的产出是中文时，需要将中文内容转化为规范的英文学术论文。

---

## 核心原则

**翻译意图和论证，不逐字翻译。**

> "Translate intent and argument, not clause order."
> — nature-writing chinese-author-workflow.md

---

## 三阶段工作流

### 第一阶段：理解（中文 → 论证结构）

先理解中文素材中的核心论证，而不是直接开始翻译。

```markdown
## 理解阶段产出示例

### 原始中文段落
"本文采用改进遗传算法求解物流配送路径优化问题。与传统遗传算法相比，
改进算法引入了实时交通权重矩阵，使得配送距离缩短了18.3%。"

### 提取的论证结构
- Problem: logistics route optimization
- Method: improved GA with real-time traffic weighting
- Result: 18.3% reduction in delivery distance
- Comparison: vs traditional GA
```

**关键转换表**：

| 中文常见表述 | 对应英文论证意图 |
|-------------|----------------|
| "本文建立了..." | Passive: "A model is developed..." |
| "针对...问题" | "To address [problem]..." |
| "结果表明..." | "The results demonstrate/show that..." |
| "与...相比" | "Compared to [baseline]..." |
| "具有良好的..." | 用具体数据代替： "achieves 95.2% accuracy" |
| "具有重要意义" | 删除或替换为具体影响 |

### 第二阶段：写作（论证结构 → 英文草稿）

按英文学术论文的规范将论证结构展开为英文草稿。

#### 摘要英文化模板

```
[Context] [Problem] is a fundamental challenge in [field]...
[Gap] However, existing [method] struggles with [limitation]...
[Approach] Here we present [method] that achieves [key result]...
[Result] Compared to [baseline], our approach improves [metric] by [X%]...
[Boundary] The method is effective when [condition]...
[Implication] This enables [application/scenario]...
```

#### 常见中文→英文句式转换

| 中文 | 英文 |
|------|------|
| "本文研究了..." | "This paper investigates / examines / addresses..." |
| "我们提出了一种..." | "We propose / present / introduce a..." |
| "该模型由三部分组成" | "The model consists of three components: ..." |
| "如图X所示" | "As shown in Figure X, ..." / "Figure X illustrates..." |
| "表X列出了..." | "Table X summarizes / reports / presents..." |
| "计算得到..." | "The computed results yield / indicate / suggest..." |
| "综上所述" | "In summary / Taken together / Overall..." |

### 第三阶段：校准（英文草稿 → 润色定稿）

对英文草稿进行三轮校准：

#### 第一轮：论证校准

- [ ] 英文是否准确传达了中文的原意？
- [ ] 没有遗漏关键数据或结论？
- [ ] 没有添加中文原素材中没有的内容？

#### 第二轮：语言校准

逐句检查以下常见中式英语问题：

| 中式英语 | 修正 |
|---------|------|
| "can be able to" | "can" 或 "is able to" |
| "there are many methods to solve this problem" | "Various methods exist for solving this problem" |
| "the accuracy is improved" → 缺少比较对象 | "the accuracy is improved by X% compared to Y" |
| Long subject chains | 拆分长主语：将 "本文提出的基于遗传算法..." 改为 "The GA-based method proposed in this paper..." |
| "make the model more better" | "make the model better" 或 "improve the model" |

#### 第三轮：动词校准

对照证据强度选择合适的动词：

| 证据强度 | 推荐动词 | 不推荐 |
|---------|---------|--------|
| 有直接数值证据 | show, demonstrate, establish | prove, verify(过度) |
| 有趋势性证据 | suggest, indicate, reveal | show(过硬) |
| 理论分析 | may, could, appear to | can, will(过强) |

## 常用学术短语库

### 描述方法

```
We develop a [model] based on [approach].
The proposed model integrates [component A] with [component B].
A [method] is employed to solve the [problem].
The model consists of three stages: [stage 1], [stage 2], and [stage 3].
```

### 描述结果

```
The results demonstrate that [claim] with an improvement of [X%].
Compared to the baseline [method], our approach achieves [metric].
The model converges within [N] iterations, demonstrating [property].
Sensitivity analysis reveals that [finding].
```

### 描述局限性

```
The model assumes [assumption], which may not hold when [condition].
When [condition] exceeds [threshold], the performance degrades by [extent].
Further validation is needed before applying to [scenario].
```

### 描述意义

```
This approach enables [application] in real-world scenarios.
The findings provide insights for [field/practice].
The framework can be extended to [related problem].
```

## 常见错误清单

| 错误类型 | 示例 | 修正 |
|---------|------|------|
| 中文直译 | "solve the problem of traffic" | "address the traffic routing problem" |
| 过度冠词 | "the model can..." | "The model can..."（英文需要冠词） |
| 缺少冠词 | "Accuracy is 95%" | "The accuracy is 95%" |
| 复数错误 | "the data is..." | "the data are..."（正式用法） |
| 介词搭配 | "based on this basis" | "on this basis" 或 "based on this" |
| 冗长表述 | "due to the fact that" | "because" |
| 过度从句 | 一句多个 which/that | 拆分为短句 |
