# 论文章节模板

章节名称和顺序首先服从当届官方模板。官方没有固定章节时，按国赛优秀论文惯例使用以下成稿结构（不是机械套用，而是按题目内容取舍）。**每个部分写入草稿前先读 `references/优秀论文写法指南.md` 对应章节，需要实证句模/频率时再读 `references/优秀论文语料分析报告.md` 对应小节**；本文件只给结构骨架与每部分的优秀论文呈现方式。

1. 摘要页（含标题和关键词，独立一页）
2. 问题重述（1.1 问题背景 + 1.2 问题提出/问题要求）
3. 问题分析（2.1 问题一的分析、2.2 问题二的分析……）
4. 模型假设（逐条编号）与符号说明（三线表）
5. 数据预处理（如题目含数据）
6. 各子问题的模型建立、求解、验证和结果（每问一节，固定"建立→求解→结果分析"）
7. 模型的分析与检验（灵敏度、稳健性或误差分析）
8. 模型的评价与推广
9. 参考文献
10. 附录（支撑材料文件列表 + 完整可运行源程序）

官方硬性约束（以当届为准）：摘要原则上不超一页、页码从摘要页"1"开始；正文不要目录、不超过 30 页；附录页数不限且必须含支撑材料文件列表与全部可运行源程序；电子版第一页必须是摘要页。

语料实测的编号习惯（2021–2025，64 篇）：问题重述常为第 1 节（`1 问题重述`/`一、问题重述`）、问题分析常为第 2 节（`2 问题分析`）、模型假设常为第 3 节、符号说明最常为第 4 节（`四、符号说明`）、建模正文常为第 5 节（`五、模型的建立与求解`）、模型评价多为第 6–7 节（`六、模型的评价`/`七、模型的评价与推广`）、参考文献多为第 7–9 节、附录最后。编号可以随题目调整，**顺序保持"重述→分析→假设→符号→建模→检验→评价→文献→附录"**。

## 摘要

最后写。"1+N"结构：

- 总述段：一句背景 + "本文针对……，通过/基于……方法，建立……模型，并利用……算法求解" + 核心结论；
- 每问一段（N）：**针对问题一，**……（方法结合题目 + 求解思路 + 含关键数值的主要结果）；
- 末段：模型检验/灵敏度结论与总体评价。

篇幅 300–1000 字、约 3/4–4/5 页；不出现公式、数学符号、表格；每个数值与正文一致；不用"较优/较好"等含糊词；关键词 4–6 个。

## 问题重述

- 1.1 问题背景：用自己的话概括（背景繁琐→压缩；简单→适当补充领域知识；适中→改写语序重构），绝不照抄题面；
- 1.2 问题提出/问题要求：以"本文需要解决以下问题：……"或"问题一：……问题二：……"列出官方明确编号的子问题及其关键参数、条件、约束、评价口径；
- 篇幅约 1/2 页、不超过一页；不能虚构背景数据。

## 问题分析

四要素：已知条件/参数/数据 → 宏观分析确定关键 → 大致求解思路（可采用的方法）→ "该问题已通过××模型求解"的引出。每一小问单独成段（"2.1 问题一的分析：……"）；不写结论、不写具体数值；与摘要对应段落不雷同；多步骤思路配技术路线/问题关系图（图后必须跟分析文字）。成稿排版时紧跟问题重述。

## 模型假设与符号说明

- 模型假设：一般 3–6 条逐条编号（`假设1：`或`1.`）；来源为题目直接条件、合理简化、模型自身需要、数据/参数设定；强假设给合理性说明；每条可被正文建模处引用，不写放之四海皆准的宽泛项。
- 符号说明：三线表（符号 | 含义 | 单位），按论文中出现顺序排列；一个符号只表示一个含义；临时变量在首次出现处解释；可加表注"未申明的变量以其在符号出现处的具体说明为准"。

## 数据预处理（如题目含数据）

数据来源与字段说明 → 缺失/异常/重复处理（每步给"处理前 → 处理后"数量/比例对比）→ 特征构造/变换 → 处理后数据概况表。预测类明确训练/验证划分、防数据泄漏；数值口径与正文一致。C/E/D 类题目通常单列本节。

## 模型建立与求解（每问固定四小节）

1. 问题的分析：该问输入输出、决策变量、目标、约束、评价指标；
2. 模型的建立：简化思想 → 变量与参数 → 数学表达 → 目标函数 + 约束 + 约束说明，并讲清"模型元素 ↔ 问题元素"映射与适配理由；
3. 模型的求解：算法原理/依据/步骤（Step 式步骤）、软件与参数、流程框图；禁止"用 MATLAB 求得："直接出结果；
4. 结果分析：结果表/图 + 图后紧跟分析（趋势、关键数值、结论含义）；每问必须给出数值答案或明确结论。

每个子问题最多两个独立模型体系；同一物理机制的基础近似和高精度展开按一个模型族组织。模型选择以题目适配和证据为准，不做无脑套模型。

## 模型的分析与检验

必写三件套，每件按"方法 → 结果（表/图）→ 图后分析 → 结论"组织：

- 灵敏度分析：关键参数 ±5%/±10%/±20% 扰动，表格或曲线展示结果变化并给出稳定性判断与建议；
- 误差/稳定性分析：预测类训练/验证误差、随机算法多次运行均值±标准差、数值方法步长收敛性；
- 约束回代/对比验证：最优解回代全部约束输出值/边界/松弛量，或与基准方法/精确解/真实数据对比。

## 模型评价与推广

优点（突出但不夸大、与模型机制/结果挂钩）→ 缺点（不回避但写不影响大局的）→ 改进方向（基于缺点、不标新立异）→ 推广（结合类似实际问题的可迁移场景）。局限必须来自假设、数据、算法或验证结果。

## 参考文献

GB/T 7714 格式；正文右上角方括号标注、与文末条目双向对应；建议 ≥8 条且覆盖背景、模型方法、检验依据；只写真实可溯源文献，中文文献必须核验。

## 附录

支撑材料文件列表（代码/数据/中间结果）+ 全部完整可运行源程序（与正文结果一致）；确实没有用到程序时注明"本论文没有用到程序"；自主查阅的数据、复杂求解过程、繁琐结果图表可放附录；正文应在相应位置出现"见附录"引用；附录数据与正文不矛盾。
