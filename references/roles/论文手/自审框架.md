# 论文自审框架

本清单是论文手的作者自检，不替代 `W1`、`W2` 独立 Subagent 验收。

## 一、官方规则

- [ ] 已记录目标竞赛、届次、官方规则和官方模板来源。
- [ ] 页面、摘要页、编号、页数、字体、提交格式等逐项符合当届官方文件。
- [ ] 未把本 Skill 默认值或往届经验写成官方规定。

## 二、内容与证据

- [ ] 长篇正文前的证据大纲已由独立质检 Subagent 执行 `W1` 并返回 `PASS`。
- [ ] 每个结论都有真实代码结果、图表、公式或文献支撑。
- [ ] 摘要中的数值与正文、表格、图和复现清单一致。
- [ ] 每道子问题最多两个独立模型体系；物理模型的不同近似按模型族说明清楚。
- [ ] 没有虚构背景数据或未核验引用。
- [ ] 局限和适用边界具体、可追溯。

## 三、国赛优秀论文写法自查（对照 `references/优秀论文写法指南.md`，实证依据见 `references/优秀论文语料分析报告.md`）

- [ ] 摘要为"1+N"：总述（背景+方法+模型+核心结论）→ 每问一段（方法结合题目+关键数值）→ 末段检验结论；无公式/数学符号/表格；数值与正文一致。
- [ ] 问题重述为 1.1 背景 + 1.2 提出，用自己的话改写，没有照抄题面。
- [ ] 问题分析每小问单独成段（"问题一的分析：……"），只讲思路不写结论和数值；与摘要对应段落不雷同；配技术路线图时图后跟分析。
- [ ] 模型假设 3–5 条逐条编号，来源覆盖题目条件/合理简化/模型需要/数据设定；强假设有合理性说明；每条可被正文引用。
- [ ] 符号说明为三线表（符号|含义|单位），按出现顺序排列，无重复或冲突符号。
- [ ] 数据预处理每步给出"处理前 → 处理后"的数量/比例对比；预测类明确训练/验证划分、防数据泄漏。
- [ ] 每问建模与求解四小节齐全：问题的分析 / 模型的建立 / 模型的求解 / 结果分析；模型元素↔问题元素映射清楚。
- [ ] 求解说明算法原理与参数，没有"用 MATLAB 求得："直接给结果；每问都有数值答案或明确结论。
- [ ] 检验三件套齐全：灵敏度（±10%/±20%）、误差/稳定性、约束回代/对比验证；每件按"方法→结果→分析→结论"组织。
- [ ] 评价与推广的优缺点与模型机制/结果挂钩，缺点可接受，推广有具体场景。
- [ ] 参考文献 ≥8 条、GB/T 7714、正文标注、双向对应、全部真实可溯源。
- [ ] 附录含支撑材料文件列表 + 完整可运行源程序（无程序注明"本论文没有用到程序"）。

## 四、文档结构

- [ ] Word 分支的公式是可编辑 OMML；LaTeX 分支的公式是可编译源码。两者均无公式截图。
- [ ] Word 与 LaTeX 的正文、数据、图表、公式和结论一致。
- [ ] 已分别核对 PDF 总页数、正文起始页、附录起始页和正文页数；官方正文上限未错误计入摘要或附录，官方硬约束和非官方质量目标已明确区分。
- [ ] 默认至少包含 8 幅正式图，其他竞赛与 CUMCM 使用同一图数基线；若按官方规则或用户要求调整，已记录依据。
- [ ] 每个子问题至少有 1 幅正式图支撑关键结论，没有把全部图集中在问题一或单一子问题。
- [ ] 表格可编辑，每幅图和每个表都有连续编号、题注及正文引用，没有孤儿图表。
- [ ] 参考文献与正文引用双向对应，DOI 和出版信息已核验。
- [ ] 不含 `[待补充]`、模板示例正文或临时占位符。

## 五、技术验证

- [ ] Word 分支的 `self_check.py` 和 `office/validate.py` 通过。
- [ ] LaTeX `doctor`、真实编译和资源/源码/PDF 校验全部通过；无未解析引用或文献，全部子问题有正式图，代码与图表副本未漂移，PDF 构建清单与当前源码哈希一致，空白页、页面尺寸、字体嵌入和图片 DPI 合格。
- [ ] LaTeX→DOCX 转换无未批准 Pandoc 警告，`.conversion.json` 的输入、输出和模板哈希与实际文件一致。
- [ ] 渲染抽检通过，分页、页眉页脚、公式和图表无异常。
- [ ] 默认同时交付 `完整论文.docx`、完整 LaTeX 源码项目及其编译 PDF；用户明确只要一种格式时已按要求缩减。
- [ ] 所需格式冻结后已由独立质检 Subagent 执行 `W2` 并返回 `PASS`。
- [ ] `W1`、`W2` 通过后相关正文、数据、图表和规则未发生未经复验的实质变化。
