# LaTeX 论文格式规范

## 唯一权威来源

论文结构、文档类、页面、摘要页、编号、字体、页数和提交文件必须遵循目标竞赛当届官方规则与官方 LaTeX 模板。内置模板只在没有官方模板时提供构建基线。

## 模板驱动生成

1. 将官方模板项目完整复制到 `PROJECT_ROOT/完整论文-LaTeX/`，保留 `.tex`、`.cls`、`.sty`、`.bst`、`.bib`、字体和模板图片。
2. 确认主入口文件；模板入口位于子目录或有多个候选 `.tex` 时，不猜测，按官方说明通过 `--main` 显式选择。
3. 只编辑复制件中的正文与明确占位位置，不重写官方导言区、文档类和固定页。
4. 把编程手的真实图表和核验后的参考文献放入项目，使用项目内相对路径；图表和代码的权威版本仍保留在 `PROJECT_ROOT`。
5. 由官方模板决定编译引擎和参考文献后端；未指定时，中文基线使用 XeLaTeX。
6. 保留初始化生成的 `latex-project.json`，其中模板来源、版本、哈希、主入口和资源绑定必须与实际项目一致。
7. 代码和图表复制到 LaTeX 项目后立即执行 `latex_paper.py bind`，禁止两处独立修改。

详细命令与校验能力见 `<SKILL_ROOT>/tools/latex/SKILL.md`。

## 公式、图表和引用

- 公式保留为原生 LaTeX，并在实际编译 PDF 中检查换行、编号和字体。
- 每幅图和每个表都有题注、真实内容与 `label`，正文在浮动环境外至少一次使用 `ref`、`autoref` 或同类命令引用；空环境不计图表。
- 每个子问题至少有一幅正式结果图，标签使用 `fig:q1-*`、`fig:q2-*` 等可校验格式，并在质量校验命令中通过 `--questions` 完整声明。
- 图只使用编程手真实生成的文件；可保留 SVG 源图，但 LaTeX 安全编译链只直接引用同源导出的 PDF、PNG、JPG/JPEG，不依赖 shell escape 临时转换 SVG/EPS。
- 正文 `cite` 键必须能在 `.bib` 或 `bibitem` 中找到；手工参考文献不得成为未引用条目。

## 编译与校验

优先使用 `latexmk` 完成交叉引用与参考文献构建，不启用 shell escape，也不读取项目级 `.latexmkrc`。构建工具在系统临时目录中的完整项目副本内编译，输出固定回收至项目 `build/`；副本或原始项目哈希发生变化即拒绝发布。未安装 `latexmk` 时，仅允许没有外部 BibTeX/BibLaTeX 文献库的项目回退为两次引擎编译。缺少 TeX 引擎、参考文献后端或宏包时明确报告环境问题，不自动联网安装或静默换引擎。

交付前必须同时满足：

- 源码不含模板占位符、越界文件引用或被禁用的文件/命令执行指令；
- `doctor` 已确认所选引擎、参考文献后端、PDF 审计工具和所需的 Pandoc 可用；
- 实际编译成功，日志无未解析引用和文献；未获明确批准的预警会阻断发布；
- 篇幅、公式、非空图表、全部子问题图覆盖、图文关联与参考文献对应检查通过；
- PDF 旁存在通过的 `.build.json`，且当前源码哈希、PDF 哈希、主入口与清单一致；
- 分别记录编译 PDF 的总页数、正文起始页、附录起始页和正文页数；官方正文上限不得用含摘要与附录的 PDF 总页数替代，并检查空白页、页面尺寸、字体嵌入和位图 DPI；
- 核对 `PROJECT_ROOT` 权威代码/图表与 LaTeX 资源副本的哈希绑定，任何漂移都先同步并重新绑定；
- 打开 PDF 抽检摘要页、分页、页眉页脚、字体、公式、表格、图片和参考文献。

## 交付

交付完整源码项目 `PROJECT_ROOT/完整论文-LaTeX/`、由该项目实际编译得到的 `PROJECT_ROOT/完整论文.pdf`，以及 PDF 同名构建清单。不要只交一个脱离 `.cls/.sty/.bib` 依赖的 `.tex` 文件，也不要用无清单或哈希不匹配的旧 PDF 代替当前构建结果。
