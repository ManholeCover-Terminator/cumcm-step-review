# 国赛优秀论文语料分析报告（2021–2025，64 篇）

> 本文件是 `优秀论文写法指南.md` 的证据库。数据来自对 2021–2025 年全国大学生数学建模竞赛 64 篇获奖论文
> （覆盖 A/B/C/D/E 全部题型）的 OCR 全文统计与逐篇细读。写作任何一部分前，先读 `优秀论文写法指南.md`
> 对应章节；需要核对"优秀论文实际怎么写的"时，再查本文件的统计与实例。

## 1. 语料与方法

- 论文来源：`优秀论文/` 目录下 2021–2025 五届优秀论文，OCR 全文清洗后进入语料库。
- 覆盖题型：A 题（物理/机理建模）、B 题（优化/运筹）、C 题（数据/统计/预测）、D 题（优化/概率）、E 题（数据挖掘/机器学习）。
- 统计口径：章节标题按"编号+标题"模式扫描（`1 问题重述`、`四、符号说明`、`五、模型的建立与求解` 等）；写法信号按关键词计数。

## 2. 章节结构与顺序（实测频率）

### 2.1 成稿章节顺序（绝大多数优秀论文一致）

```text
摘要（含标题、关键词，独立一页）
1  问题重述（1.1 问题背景 + 1.2 问题提出/问题要求）
2  问题分析（2.1 问题一的分析、2.2 问题二的分析……）
3  模型假设（假设1/2/3……，逐条编号）
4  符号说明（三线表：符号 | 含义 | 单位）
（可选）模型准备：坐标系设定、数据准备、基础定义（约 1/10 论文有）
5  模型的建立与求解（5.1 问题一、5.2 问题二……每问固定"建立→求解→结果分析"）
6  模型的分析与检验（灵敏度/误差/稳定性，可并入每问结果后）
7  模型的评价与推广（优点→缺点→改进→推广）
参考文献（GB/T 7714）
附录（支撑材料文件列表 + 完整可运行源程序）
```

### 2.2 各章节出现频率（64 篇）

| 章节 | 出现率 | 常见编号写法 |
| --- | --- | --- |
| 摘要 | 92% | 标题下直接写 |
| 关键词 | 80% | 摘要末尾 |
| 问题重述 | 83% | `1 问题重述`、`一、问题重述` |
| 问题背景 | 59% | `1.1 问题背景` |
| 问题提出/问题要求 | 20% | `1.2 问题提出`、`1.2 问题要求` |
| 问题分析 | 91% | `2 问题分析`、`2.1 问题一的分析` |
| 模型假设 | 83% | `3 模型假设`、`三、模型假设`、`2、假设` |
| 符号说明 | 94% | `四、符号说明`（最主流，30 篇） |
| 模型建立与求解 | 72–90% | `五、模型的建立与求解`、`一/二/三/四…模型的建立与求解` |
| 模型检验（独立章节） | 23% | `模型检验`、`模型的检验` |
| 灵敏度/敏感性（独立章节或内容） | 19% / 36% | `灵敏度分析`、`敏感性分析`（内容含灵敏度信号的论文 36%） |
| 模型评价 | 28% | `六、模型的评价`、`七、模型的评价与推广` |
| 参考文献 | 98% | `七、参考文献`、`八、参考文献` |
| 附录 | 92% | `八、附录`、`九、附录`、`十/十一、附录` |

结论：**章节编号不是固定格式，但"重述→分析→假设→符号→建模求解→检验→评价→文献→附录"的顺序高度一致**；
符号说明绝大多数排在建模正文之前（常为第 4 节）；问题分析常为第 2 节且每小问单独成段。

## 3. 各章节实测写法

### 3.1 摘要

- 篇幅：300–1000 字，获奖论文常见约 3/4–4/5 页；实测摘要字符区间约 1000–1400（OCR 含标题）。
- 结构："1+N"——总述段 + 每问一段 + 末段评价。**每问一段均以"针对问题一/二/三……"开头**。
- 每问内容：方法（必须结合题目：以什么为特征/目标、建立什么模型）+ 求解思路 + 关键数值结果。
- 结尾：模型检验/灵敏度结论与总体评价。
- 禁止：公式、数学符号、表格；"较优/较好"等含糊词。

**实测句模（2021–2025 高频）**：

> 本文针对……问题，基于/利用……数据，通过/采用……方法，建立……模型，并使用……算法求解。
> 针对问题一，首先……（预处理/分析），建立……模型，求得……（关键数值）。
> 针对问题二，在问题一基础上，以……为决策变量、以……为目标函数建立优化模型，求得最优……为……。
> 最后，对模型进行灵敏度分析与误差检验，结果表明……，说明模型具有良好的稳定性/适用性。

**实例（2025_A_A196 摘要开头）**：

> 本文针对无人机投放烟幕弹最优策略的研究，首先给出了导弹、烟幕弹等物体的位置函数，同时对有效遮挡的判别式进行了详细的说明。……针对问题一：……建立数学模型……求得烟幕弹对 M1 的有效遮蔽时长为 1.3916s。

**实例（2024_D_D033 摘要结尾）**：

> 对于所给参数值，运用 Matlab 软件计算得出最大概率 P(0,0)=0.0830。……关键词：反潜深弹；命中概率；正态分布；三重积分；优化算法

### 3.2 问题重述

- 篇幅：约 1/2–1 页。
- 结构：`1.1 问题背景`（用自己的话概括背景，绝不照抄题面）+ `1.2 问题提出/问题要求`（列出官方子问题）。
- 问题提出写法："本文需要解决以下问题："或直接"问题一：……问题二：……"逐条列出，保留关键参数与条件。
- 背景写法：背景繁琐→压缩；背景简单→适当补充领域知识（可查资料）；适中→改写语序重构。

**实测句模（2022_A_A171）**：

> 1.1 问题背景 ……波浪能作为一种储量大、无污染的可再生能源，具有很大的开发潜力。
> 1.2 问题要求 问题1 仅考虑垂荡……；问题2 在问题1 的基础上……；问题3 ……；问题4 ……

### 3.3 问题分析

- 篇幅：不超过 1–2 页。
- 结构：`2.1 问题一的分析`、`2.2 问题二的分析`……每问单独成段。
- 内容四要素：题目已知条件/参数 → 宏观分析确定关键 → 大致求解思路（方法/模型）→ 引出"建立××模型求解"。
- 不写结论、不写具体数值结果；与摘要对应段落不雷同。
- 多步骤思路配技术路线图/问题关系图（约 38% 论文有流程图）。

**实测句模（2021_B_B007）**：

> 2.1 问题一的分析 问题一要求探讨……。在第一小问中，观察附件1中的数据，发现……，利用皮尔逊相关系数判断数据是否存在相关性……最终确定温度对……存在二次函数的关系。

### 3.4 模型假设

- 数量：3–6 条，逐条编号（`假设1：`、`1.`、`1、假设`）。
- 内容：题目直接条件、合理简化、模型自身需要、数据/参数设定；强假设给合理性说明。
- 每条假设可被正文建模处引用；不写放之四海皆准的宽泛项。

**实测句模（2025_A_A196）**：

> 1. 将导弹、无人机、烟幕弹、烟幕云团中心以及真实目标均视为质点进行运动学分析。
> 2. 不考虑空气阻力、风速等环境因素对无人机和导弹飞行的影响。
> 3. 烟幕云团形成后，球心在垂直方向以 3m/s 的速度匀速下沉。

### 3.5 符号说明

- 形式：三线表（符号 | 含义 | 单位），94% 论文都有；最常排在第 4 节（`四、符号说明`）。
- 按论文中出现顺序排列；一个符号一个含义；首次出现处仍应解释。
- 常见备注：`注：未申明的变量以其在符号出现处的具体说明为准。`

### 3.6 数据预处理（C/E/D 类必写）

- 结构：数据来源与字段说明 → 缺失/异常/重复处理（前后数量/比例对比）→ 特征构造/变换 → 处理后概况表。
- 约 44% 论文单列"数据预处理"；其余并入各问建模前的数据处理小节。
- 预测类明确训练/验证划分，防数据泄漏；数值口径与正文一致。

**实测句模（2021_E_E014）**：

> 2.1 数据预处理 由于在对中药材进行光谱采集的过程中，会受到……等多种因素的干扰，因此获取的光谱数据除含有样本本身的大量信息以外，往往还含有与测试样本无关的成分……所以我们必须对光谱数据进行去噪，可以使用 Savitzky-Golay 卷积平滑法和标准正态变量变换（SNV）对光谱数据进行预处理。

### 3.7 模型的建立与求解（正文主体，每问固定四小节）

每问写法（以 `5.1 问题一的模型建立与求解` 为例）：

1. 问题的分析（该问输入输出、决策变量、目标、约束、评价指标）；
2. 模型的建立：简化思想 → 变量与参数 → 数学表达（公式编号）→ 目标函数 + 约束 + 约束说明；
3. 模型的求解：算法原理/依据/步骤（Step 1/2/3，约 53% 论文有算法步骤）、软件与参数、流程框图；
4. 结果分析：结果表/图 + **图后紧跟分析**（趋势、关键数值、结论含义）。

**实测句模（2024_A_A053）**：

> 5.1.1 舞龙队运动状态模型的建立 在本问题中，……因为极坐标中的极径与极角关系常被用于描述物体的旋转运动，所以我们可以在极坐标系中用阿基米德螺旋线方程来描述……

### 3.8 模型的分析与检验

- 实测高频信号：误差分析 75%、拟合优度/R2 72%、迭代 55%、收敛 36%、灵敏度/敏感性 36%、RMSE/MSE/MAE 22%、鲁棒 17%。
- 必写三件套：灵敏度分析（关键参数 ±5%/±10% 扰动，表格或曲线）；误差/稳定性分析（预测类训练/验证误差、随机算法多次运行均值±标准差）；约束回代/对比验证。
- 每件按"方法 → 结果（表/图）→ 图后分析 → 结论"组织。

**实测句模（2021_B_B007）**：

> 根据问题二中的分析可知，温度等自变量对因变量的变化有着强烈的影响，因此我们通过对 C4 烯烃收率的回归方程中温度的系数进行灵敏度分析，使其值经过上下 5% 的数据波动，绘制出 C4 烯烃收率的变化情况……温度的回归系数在 10% 的变化区间内引起了 C4 烯烃收率 18% 的变化，比较稳定，因此表明模型具有良好的灵敏性。

### 3.9 模型的评价与推广

- 结构：模型的优点（逐条编号，与模型机制/结果挂钩）→ 模型的缺点（逐条编号，不回避但不写致命缺陷）→ 改进方向 → 模型的推广（1–2 段）。
- 标题常为 `六、模型的评价` 或 `七、模型的评价与推广`。

**实测句模（2025_A_A196）**：

> 模型的优点：本文对……做了详细分析，给出了精确的……，同时没有简单地假设"……"，而是敏锐地抓住了问题的核心……体现了建模过程的数学严谨性。
> 模型的缺点：符号系统略显繁琐…… 模型的推广：本文的模型是在理想情况下进行，没有考虑到……在实际的问题研究中，这些都是不可忽略的因素。

### 3.10 参考文献与附录

- 参考文献：98% 论文有；GB/T 7714 格式；正文右上角方括号标注；建议 ≥8 条且真实可溯源。
- 附录：92% 论文有；支撑材料文件列表 + 完整可运行源程序；正文见附录引用（66% 论文出现"见附录/详见附录"）。

## 4. 图表实证（用户定制项的回溯）

- 图内无标题、图题在图下方、表题在表上方：与语料中绝大多数优秀论文的题注位置一致。
- 语料中"如图引用/见表引用"出现率约 58%/48%，**图表必须先引导再插入、插入后紧跟分析**；连续图表之间无文字为硬错误。
- 获奖论文常用流程图（38%）、散点图/折线图（17%）、热力图（9%）、可视化（42%）作为证据链，**每幅图都要有结论落点**。

## 5. 分题型写法差异

| 题型 | 常见结构差异 | 示例论文 |
| --- | --- | --- |
| A（机理/物理） | 必有"模型准备"或坐标系/受力分析；公式推导完整；每问结果常为数值表 | 2022_A_A171、2024_A_A053、2025_A_A196 |
| B（优化/运筹） | 目标函数+约束为核心；算法步骤与流程图突出；结果必须给最优解数值 | 2021_B_B007 |
| C（数据/统计） | 数据预处理独立成节；相关性/回归/预测；检验指标（R2/RMSE/灵敏度）密集 | 2023_C_C126、2025_C_C023 |
| D（优化/概率） | 情形分类讨论常见（按参数区间分情形）；概率推导+数值求解 | 2024_D_D033 |
| E（数据挖掘） | 预处理→特征提取→模型构建→性能测试的框架式写法 | 2021_E_E014 |

## 6. 使用方式

- 写作某部分前：读 `优秀论文写法指南.md` 对应章节（规定怎么写）+ 本文件对应小节（实证依据与句模）。
- 成稿后自查：对照第 2 节结构顺序、第 3 节各章节写法要点、第 4 节图表规则逐项核对。
