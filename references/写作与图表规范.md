# 写作与图表规范

> 写作前先读 `优秀论文写法指南.md` 与本文件：指南按论文部分给出国赛优秀论文的篇幅、结构、句式与评委关注点（回答"每部分写成什么样"）；需要实证句模/章节频率时读 `优秀论文语料分析报告.md`；本文件统一结构与图表格式（回答"格式怎么统一"）。写法规范冲突时，指南与语料报告的实证要求优先，官方当届模板与规则最高。

## 论文结构（国赛官方 + 优秀论文惯例）

成稿章节顺序（与国赛评阅视角一致，官方硬性要求以当届官网为准）：

1. **摘要**（独立一页，含标题和关键词）：最后撰写；"1+N"段落结构——第一段总述（背景 + 整体方法 + 核心结论），每问一段（方法 + 求解思路 + 主要结果含关键数值），末段检验与评价结论；不出现复杂公式、数学符号和表格；原则上不超一页；每个数值与正文一致
2. **问题重述**（背景 + 提出）：忠实概括题目背景、问题与要求，不照抄原文
3. **问题分析**：整体思路、技术路线、子问题依赖；成稿时紧跟问题重述
4. **模型假设**：每条假设可引用、有必要性、可参数化；与建模逻辑一致
5. **符号说明**：三线表列出符号、含义、单位；公式符号首次出现处定义
6. **数据预处理**（如题目含数据）：清洗、构造、前后对比表
7. **逐问建模与求解**（q1→qN）：每问按"建模思路 → 数学表达 → 求解方法 → 结果 → 图表 + 紧随其后的分析"
8. **模型的分析与检验**：灵敏度、误差、稳定性、约束回代、对比验证
9. **模型的评价与推广**：优缺点具体、适用边界、改进方向、可迁移场景
10. **参考文献**：GB/T 7714，正文标注，真实可溯源
11. **附录**：支撑材料文件列表 + 全部完整可运行源程序；无程序注明"本论文没有用到程序"

> 官方硬性：正文不要目录、不超过 30 页；摘要不超一页；电子版第一页为摘要专用页、页码从"1"开始；当届官方模板发布后必须优先使用并核验，本 Skill 模板只作构建基线。

## 10 部分审核顺序 → 成稿顺序映射

本 Skill 按"问题重述 → 数据预处理 → 逐问建模与求解 → 模型的分析与检验 → 模型的评价与推广 → 参考文献 → 附录 → 问题分析 → 模型假设 → 符号说明"推进写作与审核（后三部分在问题确定后再写）；**成稿排版时**问题分析紧跟问题重述，模型假设与符号说明放在建模正文之前。

## 图表规范（用户定制，硬性）

### 图

- 图内不允许出现任何标题（图上方、图下方均不写），也不画面板编号，只保留数据本身；标题信息一律放图注/图表契约。
- 图题（caption）放在图下方，不放图上方。
- 正文顺序：先引导 → 插图 → 紧随其后的分析（趋势、对比、关键数值、结论含义）。连续两张以上图表之间没有文字判为硬错误。
- 图内文字按最终印刷尺寸设定：正文标签 8.5–11pt，最小 ≥7.5pt；禁止 10pt 默认字号整图缩放，避免图大字小。
- 图型多样性：同一类型图（折线/柱状/散点/热力图/箱线等）全篇不宜超过 3 张，同类图不连续出现 3 张以上，避免审美疲劳；同一子问题多张图尽量混排不同图型。
- 布局按面板数量和证据权重选择（1×2、2×1、3×1、2×3、主图+辅助等），禁止默认 2×2；图宽以期刊栏宽为基准，国赛按正文栏宽、控制在版心内。
- 配色使用 `JOURNAL_PALETTES`（nature/science/cell/ieee/general/okabe-ito/wong，可用 `variant=` 选变体；默认 nature，严格色盲友好用 okabe-ito）；同一张图不用颜色作为唯一区分手段，配合线型/标记冗余编码；灰度预览可区分。
- 导出默认 300 DPI PNG；SVG/PDF/灰度预览按需追加。

### 表（三线表）

- 只用顶线、栏目线、底线三条线；不画竖线，不用斜线。
- 表题（caption）放在表上方（中文期刊常规）。
- 数值对齐、单位标注在表头或列名中，不重复写进每个单元格。

### LaTeX 插入示例

```latex
\begin{figure}[H]
  \centering
  \includegraphics[width=0.85\textwidth]{../figures/result_q1_xxx.png}
  \caption{问题一结果图（图题在图下方）}
  \label{fig:q1_xxx}
\end{figure}

\begin{table}[htbp]
  \centering
  \caption{表题}
  \begin{tabular}{ccc}
    \toprule
    \textbf{列1} & \textbf{列2} & \textbf{列3} \\
    \midrule
    数值 & 数值 & 数值 \\
    \bottomrule
  \end{tabular}
\end{table}
```

## 摘要撰写要点（"1+N"）

- 第一段：一句话背景 + 本文方法/模型 + 核心结论。
- 每问一段：该问方法 + 求解思路 + 主要结果（含关键数值）。
- 末段：模型检验（灵敏度/稳定性/误差）结论与总体评价。
- 最后写，从正文复制关键数值，避免摘要与正文不一致。
- 不出现复杂公式、数学符号、图表；不用"我们认为""本文将"等空泛表述。
- 美赛 Summary Sheet 是独立一页，突出方法亮点与关键结论；国赛摘要原则上不超一页（优秀论文常见 3/4–4/5 页）。
- 具体句式与"1+N"示范见 `优秀论文写法指南.md` 第一章；每问的方法必须结合题目（"以××为特征、以××为目标建立××模型"），数值必须与正文一致。

## 评审维度对应（写作时对照）

| 评审维度 | 权重 | 论文中的落实 |
| --- | --- | --- |
| 模型假设的合理性 | 20% | 假设有依据、被正文引用、可参数化 |
| 模型建立的创造性 | 25% | 每问的针对性创新/改进点 + 对比验证 |
| 结果表述的清晰性 | 25% | 定量结果 + 图表规范 + 图后分析 |
| 论文格式的规范性 | 15% | 结构与官方模板一致、排版统一 |
| 参考文献与引用 | 15% | 真实、GB/T 7714、正文标注 |

## 常见写作错误（防错清单）

- 假设没有在正文建模处引用 → 假设形同虚设
- 结论只给数值不解释含义 → "最优值为 1234.56"却没说明对应什么方案
- 图表出现但正文没有引导和解释 → 读者不知道图要说明什么
- 连续三张以上图表中间没有文字 → 论文变成图集
- 公式符号首次出现处没有定义 → 读者无法理解模型
- 参考文献是捏造或无法核实 → 严重诚信问题
- 摘要和正文数值不一致 → 摘要最后写、从正文复制数值可避免
- 正文出现内部工作流文件名、临时目录名、脚本名 → 论文不是工作日志
- 图后没有分析、图题放错位置（图题在图上方）→ 违反本 Skill 硬性图表规范
- 摘要出现数学符号/公式/图表、正文超 30 页、加目录 → 违反国赛官方格式规范
