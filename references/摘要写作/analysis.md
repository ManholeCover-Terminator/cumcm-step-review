# CUMCM 优秀论文摘要 · 8 维度深度分析

> 分析对象：`摘要汇总.md` 中的 **93 篇** 2012–2025 年全国大学生数学建模竞赛（CUMCM）优秀论文摘要。
> 引用格式：文中以 `#编号-题号` 标注出处（如 `#3-2012B017`），可对照语料原文逐条溯源。
> 用途：本文件是 `摘要写作方法论.md` 的**事实基础**，所有写作原则、模板、误区、清单均由此提炼。

---

## 维度一：写作风格（整体倾向 · 共性与差异）

### 1.1 整体倾向：学术严谨 · 简明扼要 · 逻辑清晰

93 篇摘要呈现高度一致的价值取向：**用最少的文字，把"问题—方法—结果—结论"完整、准确地传达给评审**。整体表现为：

- **结果导向**：不是"我们做了什么"，而是"我们解决了什么、得到什么数值、得出什么结论"。
- **信息密度高**：几乎每一句都携带新信息（方法名、模型名、数值、结论），极少有纯过渡的"废话句"。
- **克制**：几乎不用感叹句、反问句、夸张修饰；形容词多为"准确、合理、较好、更优、显著、稳定"这类可检验的判定词。

**例（信息密度极高的一段）** `#66-2023A092`：

> "首先，求解太阳高度角和太阳方位角来确定每一时刻太阳所在位置；接着，通过定日镜的工作原理……代入定日镜的光学效率等数据我们求出了定日镜场在不同时刻的输出热功率……最终我们得到了定日镜场的年平均光学效率为 0.6275，年平均输出热功率为 38.295MW，单位镜面面积年平均输出热功率为 0.6096kW/m²。"

短短几句，方法链（几何→机理→光学效率分解→功率计算）与量化结果俱全。

### 1.2 三类开头范式（最显著的风格差异）

摘要开头决定评审的第一印象，93 篇可归为三类：

| 范式 | 特点 | 典型例句 |
|---|---|---|
| **A. 背景意义型** | 先交代研究背景/社会意义，再自然转入本文工作 | `#9-2013厦门大学`："北京是世界上水资源严重匮乏的大都市之一，水资源短缺已经成为影响和制约北京社会和经济发展的重要因素之一。"<br>`#18-2015B309`："'打车难'一直是近年来社会关注的问题……"<br>`#88-2025A196`："烟幕干扰弹能给导弹打击的目标提供有效遮蔽，减少损失，由于低成本、效用高的特点，其在军事上得到了广泛的应用。" |
| **B. 方法直入型** | 开门见山：研究什么问题、采用什么方法路线 | `#1-2012A335`："本文针对葡萄酒的质量分析与评价问题，以置信区间、优势矩阵、逐步回归分析等方法和方差分析理论为基础，首先分析了两组评酒员评价结果……"<br>`#15-2015A095`："针对太阳影子定位问题，本文结合地理学和天文学的相关知识，建立了不同数据类型下的太阳影子定位模型……" |
| **C. 问题引入型** | 直接复述赛题任务，明确研究边界 | `#10-2014A072`："本题要求我们以嫦娥三号登月为背景，分析登月轨道参数，重点探讨了登月过程最具难度的着陆轨道设计优化……"<br>`#3-2012B017`："本文主要研究的是设计太阳能小屋时……从而最大化发电总量，同时最小化单位发电量费用的问题。" |

**倾向建议**：工程/社会应用类题目多用 A（赋予意义感）；机理/计算类题目多用 B（凸显方法与模型）；有明确"本题要求"的题多用 C。三类均可，但要**在开头段内快速落到"本文方法"**，不能停留在背景铺陈。

### 1.3 段落布局的共性骨架

```
总起段（1段）   → 研究主题 + 方法路线（可含总目标/总结果）
逐题段（N段）   → 每段对应一个赛题子问题，内部按"问题→方法→结果→结论"闭环
收束段（可选）  → "综上所述"总结 + 模型评价/推广
关键词（1行）   → "关键词：……"
```

- 逐题段用"**针对问题一/二/三/四**"（或"问题1""对于问题一"）作为显式锚点，评审一眼能对应到题目要求。
- 逐题多的摘要（如 `#76-2024A016` 有 5 问）每段保持相似结构，形成**平行排比感**，读起来节奏整齐。

### 1.4 其他可见差异

- **篇幅**：一段式（如 `#26-2018A466` 全篇两段）到多段式（如 `#66-2023A092` 四问四段）；随赛题子问题数量自然伸缩。
- **主语**：多数"本文"，部分"我们"（`#23-2017A298`："我们首先通过建立离散模型……"）。"我们"显得主动、有过程感；"本文"更正式。全文需统一。
- **有无标题**：部分摘要在其上有论文标题（`#3-2012B017`、`#32-2019B136`、`#33-2019C044`），部分直接进入正文——标题与摘要首句需呼应，不能脱节。
- **问题编号写法**：`针对问题一 / 问题1 / 对于问题一 / 对问题(1) / 针对问题一(1)` 并存，**同一篇内必须统一**。
- **表格/公式入摘要**：个别摘要直接内嵌小表格（`#36-2020A070` 内嵌温区温度表）或公式（`#47-2021A028` 内嵌抛物面方程）。**技巧**：只在结果极关键且文字说不清时用，且必须同时给数值；多数摘要仅以文字带数值即可。

## 维度二：写作语言（句式 · 表达习惯 · 术语）

### 2.1 句式结构：短句领起、长句展开，主动语态为主

- **首句短句领起**，交代本段主题：`#15-2015A095`："针对问题一，首先从地理学角度……"
- **长句展开**承载方法逻辑，用"首先/接着/然后/最后"组织内部次序：
  `#1-2012A335`："首先分析了两组评酒员评价结果……然后建立基于优势矩阵的等级划分模型……再利用关联度分析……最后对逐步回归分析法作多级嵌套改进……"
- **语态**：以**主动**为主（本文建立了……/我们采用……）；被动仅用于客观事实描述（"数据被处理为……"）。主动语态让"谁做了什么"更清晰，也更符合竞赛"展示自己工作"的语境。

### 2.2 高频表达习惯

- **总起句模板**：`本文针对……问题` / `本文研究了……` / `本文从……出发` / `本题要求我们……`
- **方法句**：`以……为基础` / `基于……` / `结合……与……` / `利用/运用/采用……` / `建立/构建/构造了……模型`
- **求解句**：`利用 MATLAB 编程求解` / `通过模拟退火算法求解` / `借助 C++ 实现`
- **结果句**：`得到/求得/得出……` / `结果表明` / `结果显示` / `计算结果为`
- **结论句**：`得到……的结论` / `验证了模型的准确性/合理性` / `说明……` / `证明……`
- **收束句**：`综上所述` / `本文……具有较好的实用性和可推广性` / `本文的亮点在于`

### 2.3 高频动词与逻辑链词（从语料统计）

- **高频动词**：建立、构建、构造、提出、设计、采用、运用、利用、求解、得到、得出、求得、验证、分析、探讨、研究、结合、简化、改进、优化、筛选、论证、评价。
- **逻辑链词**：首先→接着/然后→最后；在此基础上；进而；从而；由于……因此；考虑到……；在……的基础上；结合……；综合……
- **"我们"的使用**：`#40-2020B078`："针对问题一，我们认为参与者不可能在任意结点停留，因此我们首先证明……"——用"我们认为/我们证明"表达**推理动作**，比"本文"更有过程感。

### 2.4 专业术语使用方式

- **术语必须精确**：不写"聚类"而写"K-means 聚类"；不写"优化"而写"多目标非线性规划模型"；不写"预测"而写"灰色 GM(1,1) 预测模型"。术语的**具体程度 = 模型的落地程度**。
  `#66-2023A092`："阴影遮挡效率由投影法求出，集热器截断效率由蒙特卡洛算法求出"——把"效率"细分并绑定到具体算法。
- **首次出现给全称，必要时括注缩写**：`#44-2020C170`："根据 RAROC 理论、违约金字塔理论"；`#53-2021B160` 对方法直接写全称。
- **避免生造词**：术语要与教材/文献通行叫法一致，评审才能秒懂；个别摘要出现"序列化遗传算法"这类自造名，若非确有创新定义，慎用。

## 维度三：用词精准度（如何选准动词/形容词/名词）

### 3.1 动词选择：动作精确对应建模环节

| 环节 | 精准动词 | 说明 |
|---|---|---|
| 建模 | 建立 / 构建 / 构造 | "建立模型"最通用；"构建指标体系/评价体系"偏体系；"构造"偏具体对象（构造优势因子矩阵） |
| 引入理论 | 以……为基础 / 基于 / 依据 | 指明理论出处 |
| 算法求解 | 采用 / 运用 / 利用 | 引出具体算法 |
| 计算 | 求解 / 计算 / 推导 / 拟合 | 区分求解析/数值计算/公式推导/参数拟合 |
| 得出结论 | 得到 / 得出 / 求得 / 论证 | "求得"带数值；"论证"带命题 |
| 验证 | 验证 / 检验 / 比较 / 分析 | "验证"配模型准确性；"检验"配误差/假设 |

**例**：`#7-2013C048` 一段内动词使用极讲究：
> "我们通过最小二乘法**拟合**出观测点所在平面，再**建立**优化模型，在拟合平面上**寻找**到各观测点距离的平方和最小的点作为古塔该层的中心点。利用 MATLAB 编程**求解**……"

动词与"动作对象"一一对应，无一处含糊。

### 3.2 形容词/副词：只留"可检验"的判定词

- 好词：准确、合理、较优、最优、显著、稳定、可信、精确、鲁棒、普适、高效、接近全局最优。
- 避免：大概、大约、较多、很好、不错、非常优秀（无量化支撑的主观好评）。
- 规范用法：`结果准确率 96.75%` 优于"结果很准"；`模型具有较好的普适性`（有论证支撑）优于"模型很好"。

### 3.3 名词选择：量化 + 具体

- 把"结果"说成"**平均相对误差 MRE 为 0.09**"（`#21-2016A028`）；把"效果好"说成"**模型拟合度 R² 均达到 99% 以上**"。
- 模型名给出"形容词+方法+对象"：`基于优势矩阵的等级划分模型`、`基于热传导方程与牛顿冷却定律的温度分布模型`——名词本身就在讲方法。

### 3.4 常见"失准"与精准改法（对照）

| 失准表述 | 精准表述 |
|---|---|
| 用了一些方法 | 采用逐步回归分析与方差分析 |
| 结果不错 | 平均相对误差仅为 0.0035~0.0178，拟合数据与实测数据几乎吻合 |
| 建了个模型 | 建立基于置信区间法的检验模型 |
| 效果更好 | 较传统决策树算法预测准确率提升 15.36% |
| 得到了结论 | 得到红葡萄酒的香气和口感可通过葡萄和葡萄酒理化指标进行评价的结论 |
| "同比延长约 4.48%"（同比=对比上年同期，数模语境应表"按比例/乘性"） | 达标时间按比例延长约 4.48%（乘性延后规律） |

## 维度四：人味化表达（学术性 × 可读性）

### 4.1 让开头"有温度"但不失学术

- 背景型开头天然带人文关怀：`#79-2024A178`："'板凳龙'，亦称作'盘龙'，在浙江与福建地区广为流传，作为一种传统的民俗文化活动而备受推崇。"
- 用常识切入：`#76-2024A016`："板凳龙是一项民俗活动，盘龙时多条板凳通过把手首尾相接沿螺线盘入调头区域并盘出。"——先让读者"看见"对象，再建模。

### 4.2 用"推理动作"替代冰冷罗列

- `#40-2020B078`："我们认为参与者不可能在任意结点停留，因此我们首先证明：除了沙暴天气必须停留以外……"——"我们认为+因此我们证明"呈现思维轨迹，读者能跟住。
- `#10-2014A072`："由于正面求解条件有限……因此巧妙的使用了逆推思路"——"巧妙"虽是弱情感词，但准确地表扬了自己的思路，可读性强。

### 4.3 适度的比喻与情景化（克制使用）

- `#32-2019B136` 标题即带文学性："齐心舞动'同心鼓'，齐力牵起'协力绳'"——标题可诗意，正文保持严谨。
- 情景化描述多出现在问题背景句，而非方法句。方法句一旦抒情，就显浮夸。
- 情感色彩最弱的做法是**用"直观/清晰/形象"形容模型输出**：`#13-2014B336`："并使用 MATLAB 画出三维动态图形，进一步直观地展示了其动态变化过程。"

### 4.4 判断标准

> 人味化 = 让读者**容易读、愿意读**，而不是让文字"花哨"。凡是把意思讲得更清楚的口语化/情景化表达可以留；凡是只添情绪不添信息的话要删。

## 维度五：前后文衔接（句子间 · 段落间 · 与问题编号的锚定）

### 5.1 句间衔接手段

- **序列连接词**：首先/接着/然后/最后——在"方法流程"句群中几乎必用（`#1`、`#15`、`#66` 等）。
- **因果/递进**：由于……因此；进而；从而；考虑到……；在此基础上。
  `#29-2018B334`："考虑到求解该优化问题计算开销较大，采用多阶段决策模型进行求解……"——先给原因，再给对策，逻辑严丝合缝。
- **指代**：用"该模型""其结果""这一优化方案"回指前文对象，避免重复全名。
  `#8-2013南大`："这一优化方案对南山区未来发展是有长远意义的……"；`#13-2014B336`："最后据构建的模型给出了最优加工参数"。
- **转折**：为显示模型取舍时用"但/然而/不过"，随后给改进："正面求解难度十分大，于是对微分方程离散化"（`#10-2014A072`）。

### 5.2 段间/跨问题衔接（让全文是"一条链"而非"散装串"）

- **显式"接力"**：`#66-2023A092` 问题二"在问题二模型的基础上……"，问题三"相较于问题二……"——明确后续建模是对前问的推广。
- **沿用模型**：`#14-2015A048` 问题三"基于问题一中对影响影子长度因素的分析……建立双目标规划模型"；`#43-2020C109` 问题二"基于前文的改进的梯度下降决策树算法……"。
- **总起段预告 + 收束段回扣**：总起段说"将分四问建模"，收束段"综上所述"把各问结果串起来，形成闭环。
  `#17-2015B013`："综上所述，本文通过建立供求匹配模型，缓解程度判断模型，对出租车资源的供求匹配程度和补贴方案进行了分析……"

### 5.3 过渡要"有内容"

衔接词不是装饰。每一处"在此基础上"之后必须真的出现**新动作**（加约束/换目标/推广维度），否则就是空转过渡。

## 维度六：逻辑推进（背景→问题→方法→结果→结论）

### 6.1 标准逻辑链

```
背景/意义 → 问题界定 → 方法设计 → 求解计算 → 结果呈现 → 结论/验证 → 评价/推广
```

- **总起段**：完成「背景/问题 → 方法路线」两跳，一句话给出整体策略。
- **每个逐题段**：完成「问题（一两句复述）→ 方法（建模+算法）→ 结果（数值）→ 结论（判定/解释）」的**完整闭环**。
- **收束段**：回扣全题结论 + 模型评价/推广。

### 6.2 层层递进的三个典型手法

1. **从简到繁**：先建基础模型，再逐步加约束/加维度。
   `#1-2012A335`：问题一评酒 → 问题二分级 → 问题三关联 → 问题四评价可行性，四问模型逐层递进、环环相扣。
2. **从特殊到一般**：`#40-2020B078` 问题三"为使求解步骤更具有一般性，我们首先给出 n 名玩家的一般情况下的求解过程，然后对于第五关中只有两名玩家的情况……"。
3. **从结果反推**：`#10-2014A072`："首先……由已知的端点约束条件……建立微分方程模型。但在求解的过程中我们发现，正面求解难度十分大，于是对微分方程离散化"——呈现真实的试错—改进轨迹，逻辑可信。

### 6.3 逻辑闭环的标志句

- 每问结果后跟一句"**验证了模型的可靠性**"或"**说明模型是合理的**"（`#15`、`#23`、`#66`）。
- 模型能推广：`#23-2017A298`："其中本文建立的平行束滤波反投影重建模型还可以由二维推广至三维，可以用于太空垃圾的形状确定与分类……"——给全文一个"更大意义"的落点。

## 维度七：重点突出（篇幅 · 句位 · 强调 · 数据）

### 7.1 篇幅分配

- **总起段**约占总篇幅 15%~25%：点题 + 方法路线，不铺陈过多背景。
- **逐题段**是主体，各问篇幅**相对均衡**（若某问特别有创新，可略倾斜，但不得失衡到掩盖其他问）。
- **收束段** 1~3 句：总结 + 亮点 + 推广，不重复细节。

### 7.2 关键句位置

- **首句**：总起段首句 = 主题；逐题段首句 = "针对问题N……"（锚点）。
- **末句**：
  - 总起段末句 = 整体策略/目标（`#3-2012B017`："……从而最大化发电总量，同时最小化单位发电量费用的问题。"）。
  - 逐题段末句 = 该问结论（带判定词"更可信/更优/合理"）。
  - 全文末句 = 收束/亮点/推广，是评审印象的"落点"。
- **强调句式**：`本文的亮点在于：……`（`#12-2014A398`）；`本文的特色在于……`（`#49-2021A217`）；`本文创新性在于：一是……二是……三是……`（`#91-2025C023`）——**明确告诉评审"我哪里不同"**。

### 7.3 用数据把重点"钉死"

- 创新点配数据：`#43-2020C109`："该模型的预测准确率达到 96.75%，相较于传统的决策树算法（预测准确率为 83.87%）和 BP 神经网络模型（59.3%），预测效果分别提升了 15.36% 和 63.15%。"——创新点+对比数据，说服力最强。
- 关键结论配关键数字：`#88-2025A196`："最终求得的总最大有效遮蔽时间为 21.0770s。"

### 7.4 避免"平均用力"

如果摘要每句话都是平铺直叙的方法罗列，创新点会淹没。至少要留出 1~2 句**专门点出模型优势/创新**，并紧跟证据。

## 维度八：扩展维度（易被忽略的细节）

### 8.1 标题与摘要的一致性

- 标题（若有）与摘要首句必须呼应。`#3-2012B017` 标题"基于递归算法的建筑外表面光伏电池布局优化分析"，首句即"本文主要研究的是设计太阳能小屋时……"，方法名（递归算法）在摘要中出现，避免"标题有方法、摘要没方法"的脱节。
- 标题中的方法名/对象名，摘要正文要能承接。

### 8.2 关键词的选择

- **数量**：4~6 个（语料多为 4~5 个）。
- **构成**：方法类（算法/模型/统计方法）+ 对象类（研究对象/领域）+ 结论类（可选）。
  `#23-2017A298`："离散模型、二维平行波反投影重建、Radon变化、R-L滤波器、降噪处理"。
- **顺序**：重要的在前；对象→方法→技术。
- **用词**：与正文/摘要中出现的术语**完全一致**（不能用别名），便于检索与评审定位。
- **写法**："关键词：""关键字："均可，语料两种都有，全文统一即可；分隔符（空格/逗号/顿号）也需统一。

### 8.3 篇幅控制

- 目标区间：约 **400~800 字**（随子问题数伸缩）。5 问题目可到 1000 字，1~2 问题目应压在 300~500 字。
- **高密度例外**：若每问都带数值+验证证据（如三问 ~1100 字的 2025B 碳化硅类摘要），篇幅可放宽——**以信息密度为准，不为压字数删事实**。
- 判断标准：评审**只看摘要能否独立看懂全部四问的方法与结果**；能，则篇幅合理。
- 过长（且无密度）→ 删背景铺陈与过程细节；过短 → 补每问的量化结果。

### 8.4 图表/表格索引的引用方式

- 用「结果见表 N」「结果见附录 N」「详见 result.xlsx」等标准引用语，把摘要与正文/附录**显式挂钩**：
  `#4-2013A205`："估算出一个合理的时间范围为 5.5min~7.5min"；`#14-2015A048` 多处"具体见……"。
  `#48-2021A115`："其它参数按照规定格式存入附件材料 result.xlsx 中"。
- 引用格式统一（"见表 1" 与 "见表1" 二选一）；表号必须真实存在。

### 8.5 与正文内容的呼应关系

- 摘要中出现的每个**方法、算法、模型名、数值、表号**都必须在正文/附录**有对应**，否则是"摘要吹牛"。
- 反过来，正文最重要的创新点，**摘要必须点出**——评审常先读摘要决定是否细读正文。
- 数值精度要与正文一致（如 `#76-2024A016` 的 412.473838s 与正文同源）。

### 8.6 其他易被忽略的细节

- **数值格式**：单位统一、千分位、有效数字位数合理（结果报 3~6 位有效数字即可，不必过多）。
- **公式与符号**：摘要尽量少放公式，放则必须给出含义与数值结果（`#47-2021A028` 放抛物面方程并给具体系数）。
- **英文摘要（若要求）**：与中文一一对应，术语用规范英文（如 R²、MSE、GA），时态用过去时/现在完成时统一。
- **不出现"待填""略"**：摘要不能有任何占位。
- **不把题目原文大段照抄**：转述而非复制，体现"自己理解了"。
- **复制风险**：语料中 `#21-2016A028` 与 `#22-2016C014` 摘要完全相同——这是反例，参赛时不得照搬他人或队友的重复内容。

## 维度九：评审评分视角（评审怎么读，摘要就怎么写）

> 本维度是把"写作特征"翻译成"得分点"，供改写/评审模式使用：先站在评审角度自评短板，再针对性改写。

### 9.1 评审约 30 秒的阅读路径

国赛评审一天要看大量论文，摘要的"黄金 30 秒"大致是：

| 顺序 | 评审动作 | 对应摘要特征 |
|---|---|---|
| 1 | **结构扫描** | 有没有"总起段 + 针对问题一/二/三 + 收束 + 关键词"，问题编号是否齐全可对应 |
| 2 | **逐问找结果** | 每个问题下有没有具体数值（数字、单位、精度）；只有过程的段落=零分 |
| 3 | **找模型名** | 方法是否具体到算法/模型全名（"遗传算法"优于"优化"） |
| 4 | **找创新** | 有没有"亮点/特色/创新性在于"这类专门句子 |
| 5 | **找验证** | 有没有误差/拟合度/灵敏度/对比/求解器状态等证据 |
| 6 | **读收束与关键词** | 收束是否点出整体价值，关键词是否与正文一致可检索 |

### 9.2 五个得分点与写法映射

1. **问题对应性**：逐题段与赛题子问题严格一一对应（清单 E5）。失分表现=少问、合并问、顺序错乱。
2. **结果完整性**：每问都有量化结果（原则 3、清单 A5/D）。失分表现=只写过程不写数。
3. **方法具体性**：模型名具体到"基于××的××模型"（原则 4）。失分表现="建立了一个模型"。
4. **创新突出性**：有专门句子点出创新并配证据（原则 5、清单 C7）。失分表现=创新淹没在平铺里。
5. **表达清晰度**：结构分明、术语一致、无废词（原则 6、清单 C2）。失分表现=长句堆叠、照抄题目。

### 9.3 强/弱摘要与奖项档位

- **校赛/省赛二等 → 一等**：差距通常在于"量化结果密度"与"验证证据"——把"很好"换成"R²=0.98、误差 0.5%"即可显著提档。
- **一等 → 国一**：进一步落在"创新突出 + 验证严谨 + 篇幅克制"——评审要能在摘要里**一眼看到你的原创点**（新算法、新组合、新指标），并有数据支撑。
- 案例：`#43-2020C109` 的创新句带对比数据（96.75% vs 83.87%，提升 15.36%），就是"创新+证据"的示范。

### 9.4 用评审视角自评并转化为改写目标

1. 逐项过 [checklist.md](checklist.md) 的 ▲ 必查项，先修"0 分项"（缺结果、缺对应、方法笼统）。
2. 再修"半衰项"（创新被淹没、验证单薄）——这两项通常是奖项档位瓶颈。
3. 最后精修"衰减项"（衔接重复、篇幅、术语一致性）——决定阅读体验。

## 附：强摘要 vs 弱摘要 判别速查

| 判别项 | 强摘要 | 弱摘要 |
|---|---|---|
| 结构 | 总起段 + 逐题段（显式锚点）+ 收束/关键词 | 一团文字，看不出对应哪个问题 |
| 结果 | 每问都有量化结果（数值+单位+精度） | 只有过程描述，无结论数字 |
| 方法 | 模型名具体（基于××的××模型） | 笼统（"建立了一个模型"） |
| 验证 | 有误差/拟合度/灵敏度/对比验证 | 无验证，自说自话 |
| 衔接 | 跨问"接力"，递进清晰 | 各问并列散装，无逻辑勾连 |
| 创新 | 有专门句子点出亮点并配证据 | 创新点淹没在平铺叙述里 |
| 语言 | 术语精准、主动句、无废词 | 冗词、模糊词、"大概"式评价 |

> 本分析为 `摘要写作方法论.md`、`templates.md`、`mistakes.md`、`checklist.md` 的母本。写作时请结合语料原文（`摘要汇总.md`）反复比对学习。
