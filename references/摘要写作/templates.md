# 句式模板库

> 按功能分类的摘要句式模板，全部例句取自 93 篇国赛优秀摘要语料。出处以 `#N-题号` 标注（对应 `摘要汇总.md` 中「**N. 题号**」），可按需回溯整篇体会。
> 使用方式：先看「结构骨架」，再按当前要写的位置（总起/逐题/收束）挑选模板句，替换 `〔方括号〕` 中的内容。
> 说明：例句为从语料中**节选/微调**以展示句式，个别作了规范化处理（引号、空格、R² 记号等），含义与原句一致；确证原文请在 `摘要汇总.md` 中按编号核对。

## 0. 结构骨架（一段一问的标准 4 拍）

```
〔总起〕本文针对〔问题/对象〕……，基于〔理论/方法〕……，建立了〔模型〕……
〔逐题·①问题〕针对问题〔N〕，〔转述该问要求〕……
〔逐题·②方法〕首先……接着/然后……最后……（建模思路）
〔逐题·③结果〕求得/得到/结果表明……〔数值+单位〕……
〔逐题·④结论〕得到……的结论，验证了模型的……（可信/准确/合理）
〔收束〕综上所述，本文……，具有较好的实用性和可推广性。
〔关键词〕关键词：〔对象类词，方法类词，算法类词〕
```

## 13. 段落级改写技巧（改写既有摘要时用）

> 句子级模板解决"这句怎么写"，本节的技巧解决"这段怎么改"。改写时按需选用，每项给「改动前 → 改动后」。

### T1 摘要不放公式：模型公式一律文字点名（公式清零，非"压缩"）
**场景**：原摘要显示推导公式/整式（如 $R(\nu)=R_{01}+(1-R_{01})^{2}R_{12}+…\cos(2\delta)$、$d=1/[2n_1\cos\theta_t\cdot\Delta\nu]$），占篇幅且难读。**语料实证：93 篇国赛优秀摘要零显示公式、零整式**——同题 2025B 优秀篇 `#89-2025B060`、`#90-2025B157` 均纯文字点名公式（"给出了直接计算外延层厚度的公式"），公式本体在正文。
- 改动前：`…双光束干涉反射率公式：$R(\nu)=R_{01}+(1-R_{01})^{2}R_{12}+2\sqrt{R_{01}R_{12}}(1-R_{01})\cos(2\delta)$`
- 改动后：`…推导了考虑折射率色散的双光束干涉反射率公式，并基于相邻干涉峰的波数间距 Δν 导出厚度反演公式`
- 改动前（推导细节）：`按公式 p=⌈3600Q/η⌉ 计算每道工序中每类设备的持续工作时间；按公式 t_move=⌈400/2⌉ 计算班组1 设备到达 A 车间的初始运输时间`
- 改动后（推导细节）：`按工序工程量与设备作业效率计算各工序持续时间，结合设备初始运输时间`
- 原则：**公式清零**——模型公式用文字点名（"推导了…反射率公式""建立了…模型"）；参数符号与数值（R₀₁≈0.19、Δν、Qₘᵦ=0.35）作为行内记号保留作结果载体；公式/整式下沉正文。**删公式≠删事实**，须同步保留其后的结果证据句（清单 G4）。

### T2 去重复衔接词
**场景**：多段连用同一衔接词（"延用""基于"×N），句式单调。
- 改动前：问题三"延用问题2 的 CP-SAT 约束规划算法"；问题四"延用问题3 的 CP-SAT 两班组柔性作业车间调度模型"
- 改动后：问题三"在问题二模型基础上……沿用 CP-SAT 约束规划算法并保留设备互斥与跨车间转移约束"；问题四"在问题三模型基础上建立购置—调度联合优化模型"
- 变体库：`基于/在问题 N 模型基础上/与问题 N 相似，仅…/参考问题 N 的…，进一步…`。

### T3 结果句补对比基准
**场景**：结果数值孤立出现，看不出优化幅度。
- 改动前：`得到在 500000 元预算内……总工期压缩至 30755s`
- 改动后：`总工期由问题三的 72860s 进一步压缩至 30755s`
- 原则：涉及"改进/压缩/提升/下降"的数值，尽量给上一基准（清单 D4）。

### T4 句读与数值格式统一
**场景**：数值、单位、换算格式混乱。
- 改动前：`总完工时刻为37280 s，即10:21:20`
- 改动后：`总完工时刻为 37280s（10:21:20）`
- 规则：`数值+单位+（换算）`统一；单位规范（W/kW、cm/min、℃·s）；有效数字一致（清单 D2/D3）。

### T5 非关键信息下沉正文
**场景**：每段重复同一句无关紧要的话（如"完整作业计划见附录 B"）。
- 做法：只在首次出现处保留一次引用（"完整作业计划见附录 B"），后续各问删去或换成结论句。
- 原则：摘要每句都应携带"方法/结果/结论"，重复的索引信息只留一次（清单 F3）。

### T6 弱填充句替换
**场景**：总起段或段首有"研究对象包括……"之类低信息量句。
- 改动前：`本文围绕……问题展开研究，研究对象包括五个车间的多道固定顺序工序及班组设备资源。`
- 改动后：`针对某工业制造系统中五车间集中整修任务的多工序协同作业与设备资源配置问题，本文以工程量、设备效率与运输时间为建模基础……`
- 原则：把"研究对象"改写成"针对什么问题"，让首段直接回答"问题+方法"（范式 B）。

### T7 重复用词与双重结构消除
**场景**：同一结构词在一句内重复使用，读来拗口。
- 改动前：`针对问题四，针对女胎缺失 Y 染色体信息的判定失效问题，……`（双重"针对"）
- 改动后：`针对问题四中女胎缺失 Y 染色体信息导致的判定失效问题，……`（来源 2025C）
- 改动前：`以全过程最小板间距严格为正为可行性判据`（双"为"）
- 改动后：`以全过程最小板间距严格为正作为可行性判据`（来源 2024A）
- 原则：扫描每个介词/助词（针对/以…为…/基于/对于）在同句内的重复；保留语义，合并结构。

### T8 长枚举 / 坐标序列的取舍（视题设要求而定）
**场景**：摘要罗列大量同类数据（多对坐标、十几个并列参数），占篇幅且读来琐碎。
- 改动前：`得到编号为 FY00~FY09 无人机的定位坐标为（0,0）、（95.4389,359.8519）、（95.4446,40.1701）、（95.5725,79.7385）……（共十对）`
- 改动后·保留完整时（统一标点 + 末尾概括）：`……（0,0）、（95.4389,359.8519）、（95.4446,40.1701）……（95.5309,320.2777），基本分布在一个圆上`（坐标对内半角逗号、坐标对间顿号，末句给概括结论）
- 改动后·压缩时（仅当序列非题设交付结果）：`十架无人机定位坐标沿圆周均匀分布，整个编队的相对调整误差为 0.0398`（完整坐标表下沉正文）
- **取舍准则（先判断题设，再判断数量）**：
  1. **题设要求给出完整序列时 → 必保留，不压缩**。若赛题明确要求"给出所有/每一…的坐标/序列/方案/计划"（如 2022B 无人机要求输出编队定位坐标、调度题要求给出每台设备的作业计划），该序列就是本题的**交付结果**，摘要必须完整呈现（或按题目要求呈现），压缩会让人误以为你只算了一个概括值、漏掉了题设要求的结果。
  2. **非交付结果、属佐证性罗列，且项数 >5 同质**（并列参数/多组结果）→ 压缩为"概括式收尾 + 保留关键证明值"，完整序列下沉正文。
  3. **项数 ≤5 且每项承载独立结果信息** → 保留完整。
- 原则：压缩不改变结论（清单 G4 无遗漏）；概括后仍须保留能证明结论的关键数值（如上例 0.0398），不得把证据一并删掉。
