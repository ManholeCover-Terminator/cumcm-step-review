# 期刊配色方案

与 `scripts/plot_style.py` 中的 `JOURNAL_PALETTES` 对应，共 **7 套**（nature/science/cell/ieee/general/okabe-ito/wong），各套含默认主色板与可选变体。绘图前用 `apply_publication_style(journal=..., variant=...)` 切换，默认 `nature`（用户定制 Nature 主色板）。
MATLAB 侧使用同一套色板：`apply_publication_style(fig, "zh", "report", "cell")`（第四个参数选 nature/science/cell/ieee/general/okabe_ito/wong，默认 nature；MATLAB 固定用各期刊默认主色板，变体以 Python 侧为准）。

连续色带与发散色带：nature/cell/ieee/okabe-ito/general 用 viridis + RdBu_r；science 用 magma + RdBu_r。

## 使用规则

1. **主色用量**：单张图类别色不超过 5 个；超过时优先拆图或合并次要类别，不要硬堆。
2. **冗余编码**：同一张图不用颜色作为唯一区分手段，配合线型/标记区分（色盲与灰度打印均可读）。
3. **连续数据**：热力图/表面图用色板对应连续色带（viridis/magma/plasma）；发散数据用 RdBu_r，并保证 0 值居中。
4. **语义色**：异常/危险用红系，正常/通过用绿系，警告用橙黄系；语义色在全文保持一致。
5. **灰度检查**：导出后生成灰度预览（`grayscale_preview=True`），确认灰度下仍可区分。
6. **全文统一**：同一篇论文所有图表用同一套色板，绘图前先 `apply_publication_style(journal=...)`。
7. **色板可扩展**：如需要中文核心期刊或特定比赛模板配色，在 `JOURNAL_PALETTES` 中追加新条目并注明来源。
8. **变体选择**：同一期刊有多个变体时用 `variant=` 指定（如 `apply_publication_style(journal="cell", variant="大地色板")`）；未指定用该期刊默认主色板。
9. **色盲友好**：需要严格色盲安全时用 `journal="okabe-ito"` 或 `journal="wong"`，并配合线型/标记冗余编码。

## 使用示例

```python
from plot_style import apply_publication_style, export_figure

apply_publication_style(journal="nature", lang="zh")          # Nature 主色板（默认）
apply_publication_style(journal="cell", variant="大地色板")    # Cell 大地色板
apply_publication_style(journal="okabe-ito", lang="zh")        # 严格色盲友好
# ... 画图 ...
export_figure(fig, "figures/result_q1_xxx", dpi=300)
```
