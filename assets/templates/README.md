# 国赛论文模板（构建基线）

本目录存放国赛论文的**模板基线**，用于没有官方模板时搭建论文结构、验证编译链路。

> 重要：若目标赛题当届官方模板已发布，必须优先使用并核验官方模板（承诺书页、编号专用页、摘要专用页、页边距、页眉页脚、页码规则、提交格式）。本模板不得声称替代官方文件。

## 与官方规范（2026 年修订稿）的差距

官方纸质版论文为：第一页承诺书、第二页编号专用页、第三页摘要专用页（摘要含标题和关键词、不超一页，页码从摘要页"1"开始、页脚中部）、第四页起正文（不要目录、不超过 30 页）、正文后附录（页数不限，必须含支撑材料文件列表与全部完整可运行源程序）。

本基线模板：

- **不含**承诺书页与编号专用页——纸质版提交时需从当届官方材料中取得这两页，插入摘要页之前；电子版论文按官方要求**不要**这两页，第一页必须是摘要页（本基线天然满足）。
- 章节顺序已按官方评阅视角对齐：摘要 → 问题重述 → 问题分析 → 模型假设与符号说明 → 数据预处理 → 逐问建模与求解 → 模型的分析与检验 → 模型的评价与推广 → 参考文献 → 附录。
- 附录章节模板预留了"支撑材料文件列表 + 源程序"与"本论文没有用到程序"的位置。
- 正文篇幅上限（30 页）与摘要单页限制属于排版约束，需在写作与编译后人工核验（可用 `scripts/paper_check.py` 与最终验收流程检查）。

> 注意：`main.tex` 中的 `LATEX_TEMPLATE_*` 是待替换占位符，包含下划线，未替换前直接编译会报
> "Missing $ inserted" 类错误。**先替换全部占位符（标题/摘要/关键词/正文）再编译**；工具链的
> `latex_paper.py` 也会在验收时检查占位符是否残留。

## 当前内容

- `main.tex` + `references.bib`：国赛 LaTeX 模板基线（与 `tools/latex/assets/templates/cumcm/` 同源）；编译命令 `xelatex main.tex`（跑两遍解决交叉引用）。
- `论文模板.docx`：Word 论文格式基线（来自 `math-modeling` 论文手角色）。

工具链内另有英文模板：`tools/latex/assets/templates/mcm-icm/`。
